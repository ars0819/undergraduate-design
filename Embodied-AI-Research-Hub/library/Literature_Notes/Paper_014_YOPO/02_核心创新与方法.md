## 一、创新的分级

### A. 最重要的创新（只选 1 项）

> **把三段式规划压成"在运动基元锚点上做逐格回归"的单阶段网络，并用"ESDF 数值梯度反传"的引导学习来训练它。**

两个部分缺一不可：
- **结构上**：单阶段（一次前向出多条候选）= 快（1.6 ms）；
- **训练上**：引导学习（不用专家）= 不被示范上界锁死（表 I 里网络平均代价 0.050 < 专家 0.078）。

如果只做结构：没有专家示范就训不出多模态的 15 条轨迹。
如果只做训练：还是三段式，延迟依然高。

### B. 其他有价值的改进

| 改进 | 价值 | 是否首创 |
|---|---|---|
| **基元坐标系**（$R_{ij}=R_z(\phi_i)R_y(-\theta_j)$） | 解决"规划不是平移不变"的问题，让全卷积头可用 | ★ 关键的工程洞察 |
| **偏移量用 $\tanh$ 有界** | 保证改进不跑出解空间 | 常见但必要 |
| **分数用 $-J$ 监督** | 把"代价"变成可学的分数 | ★ 巧妙 |
| **特权学习**（训练用真值 ESDF、推理只用深度） | 让网络在噪声下更稳 | 概念来自 [8] 等 |
| **无标签数据增广** | 随机改初始状态/目标，不用重新标注 | ★ 实用性高 |
| **只训练"高分轨迹"的末端状态** | 避免负样本干扰 | 实现细节 |

### C. 借鉴已有研究的技术

| 技术 | 来源 | 角色 |
|---|---|---|
| YOLO 的"锚点 + 偏移 + 置信度" | [13] | 核心结构灵感 |
| 运动基元库（state lattice） | [11]（作者自己前作 LPNet） | 锚点定义 |
| 多项式轨迹 + 边界值问题 | [15]（Richter et al.） | 轨迹表示 |
| ESDF 梯度优化 | [6]（Gao et al.） | 代价函数与雅可比来源 |
| 特权学习 | [8]（Agile Autonomy） | 训练范式 |
| MPPI + Hybrid A\* | [17] | 基线 |
| Flightmare | [16] | 仿真器 |
| DAgger | Ross et al. | 数据聚合 |

### D. 工程实现与实验设置

- 深度图 160×96（RealSense D455 的 16:9 缩放）；
- 5×3 条轨迹，下采样因子 32；
- 训练：Flightmare 采 **100K** 样本、50 epochs、lr 1.5e-4、batch 16、轨迹选择阈值 0.04；
- 轨迹：2 s 时窗、15 Hz 重规划（**只执行 1/30**）、50 Hz 参考；
- 部署：TensorRT on Xavier NX。

> [!important] 一句话总结分级
> **本文的原创性 ≈ "把检测的锚点范式搬到规划" + "用代价梯度替代专家示范"这两个迁移。**

## 二、核心创新的八个追问

### ① 以前的研究通常怎么处理"四旋翼高速避障"？

| 范式 | 代表 | 训练信号 | 问题 |
|---|---|---|---|
| 传统三段式 | TopoTraj、Fast-Planner | 无学习 | 延迟大（61.9 ms） |
| 模仿学习 | Deep-PANTHER、Agile Autonomy | 专家轨迹 | 上界是专家 |
| 强化学习 | CAD2RL、最小时间飞行 | 环境奖励 | 稀疏、难收敛 |
| 碰撞预测 | [12]、LPNet | 碰撞标签 | 预定义基元表达力有限 |
| **本文** | YOPO | **代价的数值梯度** | 需要真值 ESDF 训练 |

### ② 原有方法的缺点是什么？

| 缺点 | 原文依据 | 我的核查 |
|---|---|---|
| 三段式延迟 | §I："introduces additional latency, which is fatal for high-speed flights" | 表 II：61.9 ms |
| 模仿学习上界 | §I："the upper bound of the network policy is the expert policy" | 表 I 用"超过专家"反驳 |
| RL 难收敛 | §I："sparse, noisy, and delayed" | 成立，尤其对慢仿真 |
| 碰撞预测基元表达力有限 | §I："cannot represent complex trajectories" | 成立 |

### ③ 作者具体修改了什么？

**三处**：

**(1) 输入输出：端到端单阶段**
输入深度图 + 状态 + 目标方向 → 输出 $5\times3\times10$ 的张量（偏移/末端导数/分数）。

**(2) 坐标系：基元坐标系解耦**
$$R_{ij}=R_z(\phi_i)R_y(-\theta_j),\qquad x^*_{ij}=R_{ij}^{-1}x \tag{6,7}$$
把输入变换到每个基元的坐标系，再拼到特征图对应位置——解决"同一特征在不同格子应给不同预测"的矛盾。

**(3) 训练：引导学习**
把传统优化的数值梯度反传到网络：
$$\frac{\partial J}{\partial d_P}=\lambda_s\frac{\partial J_s}{\partial d_P}+\lambda_o\frac{\partial J_o}{\partial d_P}+\lambda_g\frac{\partial J_g}{\partial d_P}$$
分数再用 $\text{SmoothL1}(y_s,-J)$ 监督。

### ④ 修改发生在哪一层/哪一环？

```
[传统]
深度图 → 建图(ESDF) → 前端拓扑搜索 → 后端优化 → 轨迹
         ↑48.5ms        ↑6.1ms          ↑7.3ms

[本文]
深度图 + 状态 + 目标 → 一个网络 → 15 条候选（偏移+导数+分数）→ 取最高分 → 解多项式 → 轨迹
                        ↑1.6ms
```

**改动贯穿整条流水线**——它不是"替换其中一段"，而是**把三段合并成一段**。

### ⑤ 为什么这种改变有效？

**(a) 为什么单阶段能这么准？**
- 基元已经覆盖了视场（粗粒度）；
- 网络只需预测"从基元往哪挪一点"（细粒度）——**把大搜索问题变成小回归问题**；
- 15 条候选提供了多峰覆盖，比单一梯度下降更不容易卡住。

**(b) 为什么网络能超过专家？**
- 专家（梯度优化）**对初始化敏感**，容易卡在次优；
- 网络**从整个数据集学到了统计规律**（"这种场景通常往哪边走"），相当于有先验；
- 表 I：平均代价 0.050 vs 0.078。

**(c) 为什么需要特权学习？**
- 训练时有真值 ESDF，梯度准确；
- 推理时只有噪声深度，但网络已经学会了"在完美信息下该怎么走"的映射，对噪声更鲁棒；
- 图 6 的对比：传统方法会因为观测不足卡在障碍里，本文不会。

**(d) 为什么基元坐标系必要？**
- 全卷积头在特征图上共享权重 → 同一特征在不同位置给出相同预测；
- 但规划**不是平移不变的**：左格子该往右、右格子该往左；
- 把输入转到基元坐标系后，"往右偏"在每个格子里都是同一个含义。

### ⑥ 它引入了什么新代价？

| 新代价 | 说明 | 证据 |
|---|---|---|
| **训练需要真值 ESDF** | 真机拿不到 → 只能 sim-to-real | §II-B-2 |
| **平滑度不如 MPPI** | 37.87 vs 14.92 | 表 II |
| **真机延迟 16 ms** | 是仿真的 10 倍 | §III-C |
| **基元数量固定** | 5×3，稠密场景够不够未知 | §III |
| **深度量程 6 m** | 高速时"看不够远" | §III-C |

### ⑦ 与最接近的前人方法有什么区别？

| 维度 | TopoTraj | MPPI+A\* | Agile Autonomy | **YOPO** |
|---|---|---|---|---|
| 是否建图 | 是（ESDF） | 是（GPU） | 否 | **否** |
| 前端 | 拓扑搜索 | Hybrid A\* | 无 | **基元锚点** |
| 后端 | 梯度优化 | 蒙特卡洛采样 | 无（网络直出） | **网络回归** |
| 延迟 | 61.9 ms | 19.7 ms | 5.4 ms | **1.6 ms** |
| 安全（1/30） | 1.23 m | 1.23 m | 1.13 m | **1.63 m** |
| 平滑度 | 352.72 | **14.92** | 2324.47 | 37.87 |

**最本质的区别**：本文是**唯一"不建图 + 单阶段 + 显式多候选"**的组合。

### ⑧ 实验是否真的支持作者的主张？

| 作者主张 | 证据 | 支持度 | 我的评语 |
|---|---|---|---|
| "延迟显著更低" | 表 II：1.6 vs 61.9 | ✅ 强 | 但真机是 16 ms |
| "比专家更好" | 表 I：0.050 vs 0.078 | ✅ 强 | 只在"平均代价"上 |
| "安全性最好" | 表 II：1.63/1.28 | ✅ 强 | 两种密度一致 |
| "平滑度可接受" | 表 II：37.87 | ⚠️ 中 | 明显不如 MPPI |
| "高速更好" | 图 7 | ✅ 中强 | 但 6 m/s 以上 Agile 更优（作者承认） |
| "真机能飞" | 5.52 m/s 密林 | ⚠️ 弱 | 只有描述，无成功率统计 |

## 三、算法完整流程

### 3.1 【输入】

| 输入 | 形式 | 出处 |
|---|---|---|
| 深度图 | 160×96（仿真 96×96） | §III |
| 当前状态 | 速度、加速度（机体系） | §III |
| 目标方向 | 单位向量 | §III |

### 3.2 【预处理】

- 无效深度用**最近邻插值**填补（避免与近处障碍混淆）；
- 状态与目标方向变换到各基元坐标系（式 7）。

### 3.3 【核心模块】

| 模块 | 职责 |
|---|---|
| ResNet-18 主干 | 深度特征提取（下采样 32） |
| 基元锚点库 | 5×3 条基元的球坐标端点 |
| 1×1 卷积头（共享权重） | 逐格预测偏移/导数/分数 |
| 轨迹求解器 | $A=M^{-1}d$ → 多项式 |
| 跟踪控制器 | 几何控制器 @50 Hz |

### 3.4 【信息传递】

```
深度图 (160×96) → ResNet-18 → 特征图
状态/目标 → 变换到基元坐标系 → 拼到特征图对应位置
→ 1×1 卷积 → 每格 10 维输出（3 偏移 + 3 速度 + 3 加速度 + 1 分数）
→ tanh 约束 → 选最高分 → 解多项式 → 2 s 轨迹（只执行 1/30）
```

### 3.5 【推理流程】

```text
1. 取深度图 + 状态 + 目标方向
2. 网络一次前向 → 15 条候选（偏移/导数/分数）
3. 选分数最高的一条
4. 把偏移加到基元端点 → 得到精化后的末端状态
5. 解边界值问题 → 5 阶多项式轨迹
6. 只执行前 1/30（2 s 窗口 / 15 Hz 重规划）
7. 50 Hz 离散化为参考轨迹 → 几何控制器
```

### 3.6 【训练流程】

```text
1. Flightmare 随机重置状态，采 100K 样本（位置/姿态/深度）
2. 用真值点云计算 ESDF
3. 对每条基元：
   a. 手工计算 J 对末端状态的雅可比（式 14/17/19）
   b. 链式法则反传到网络权重
   c. 分数用 SmoothL1(y_s, -J) 监督
4. 只训练分数 > 0.04 的轨迹的末端状态
5. DAgger 微调
```

### 3.7 【机器人执行】

| 问题 | 原文回答 | 状态 |
|---|---|---|
| 重规划频率 | **15 Hz**（2 s 窗口） | §II-A-2 |
| 执行比例 | **1/30**（只执行 66 ms） | §II-A-2 |
| 参考轨迹频率 | 50 Hz | §II-A-2 |
| 推理延迟 | 1.6 ms（RTX 3060）/ 16 ms（Xavier NX） | 表 II、§III-C |
| 控制 | 几何控制器（SE(3)） | §III-C |

### 3.8 【输出】

- 一条 2 s 的多项式轨迹（三轴独立）；
- 不输出地图、不输出价值。

## 四、训练 / 推理差异对照

| 维度 | 训练 | 推理 |
|---|---|---|
| 环境信息 | **真值点云 + ESDF** | **只有噪声深度** |
| 监督 | 数值梯度 + $-J$ 分数 | 无 |
| 坐标 | 基元坐标系 | 基元坐标系 |
| 硬件 | RTX 3060 | Xavier NX（TensorRT） |
| 延迟 | — | 1.6 ms / 16 ms |

> **这就是"特权学习"的典型结构**：训练时用"上帝视角"，推理时用"凡人视角"。与 DiPLO 的 SD:DPO 是同一类思想（[[Paper_010_DiPLO/01_论文精读]]）。

## 五、方法层面的疑点清单

1. **"超过专家"只在平均代价上**，最优代价持平；且代价函数本身是人为设计的——代价低不等于飞得好。
2. **真机只有定性描述**（5.52 m/s 密林），没有成功率/碰撞率统计。
3. **平滑度明显不如 MPPI**（表 II），作者归因于加权，但没有做"提高平滑权重"的消融。
4. **16 ms 的真机延迟与 1.6 ms 的仿真差 10 倍**，论文里两个数字并列出现，容易误读。
5. **基元数量（5×3）固定**，稠密/空旷场景是否都合适未讨论。
6. **训练依赖真值 ESDF**，真机无法在线生成 → 只能 sim-to-real，而 sim-to-real 的差距未量化。

## 六、把方法浓缩成一条因果链

```text
高速飞行要求低延迟
 ├─ 原因: 三段式串行延迟大
 │    └─ 对策: 单阶段网络（基元 + 逐格回归）
 ├─ 单阶段带来的新问题 1: 规划不是平移不变的
 │    └─ 对策: 基元坐标系解耦
 ├─ 单阶段带来的新问题 2: 没有专家示范怎么训？
 │    └─ 对策: 【创新】引导学习（数值梯度反传）
 └─ 训练与部署信息不对称
      └─ 对策: 特权学习（训练用真值 ESDF、推理用深度）

结果: 1.6 ms（仿真）/ 16 ms（真机）、安全最好、密林 5.52 m/s
代价: 平滑度不如 MPPI、依赖真值 ESDF 训练
```

> 这条链最值得学的是**"单阶段带来的新问题"**：作者没有把"换成单阶段"当成一句口号，而是逐一解决它带来的两个具体障碍（坐标系、训练信号）。
