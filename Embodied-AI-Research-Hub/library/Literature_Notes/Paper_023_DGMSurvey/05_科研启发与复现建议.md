## 一、它给我的最重要的一张图：速度-表达力 trade-off

```mermaid
flowchart LR
    A["快 / 弱"] --> B["GMM"]
    B --> C["分类 bin"]
    C --> D["采样模型"]
    D --> E["扩散"]
    E --> F["EBM / 慢 / 强"]
```

**【原文证明】**：
- 采样模型"tend to have very fast inference times"；
- 扩散"generate high quality samples due to the iterative denoising process"；
- EBM 采样"usually requires MCMC"（最慢）。

**【我的判断】**：**我的加速研究本质上是在移动这条曲线**——不是"沿着曲线选一个点"，而是"用更少的代价拿到同样的表达力"。

具体来说，移动曲线有四种手段：
| 手段 | 代表论文 | 怎么移 |
|---|---|---|
| 少步蒸馏 | TinyVLA（P001）、TrajWAM（P009） | 把 $T$ 步压到 1–4 步 |
| 缓存/跳步 | （我没读到） | 复用中间结果 |
| 换生成范式 | Cue the Flow（P008） | 用热图替代迭代 |
| 量化/剪枝 | SPAR（P002）、OpenVLA（P004） | 降低单步代价 |

**这四类恰好构成一个完整的"加速谱系"**——而综述没有系统整理它们，**这就是我的空间**。

## 二、A–H 八问

### A. 对 VLA 推理加速的启发

**【原文证明】**
1. 五类的推理代价差异明确（1 步 vs 多步 vs MCMC）；
2. 扩散"质量高但慢"是结构性的。

**【合理推测】**：**加速研究应该同时报告"步数"与"单步代价"**——因为总代价是两者乘积。
- 蒸馏减步数；
- 量化/剪枝减单步；
- 两者可以相乘。

**【待验证】**：蒸馏到 1 步后，量化还能带来多少收益？（可能因为单步代价占比变了）

### B. 对动作分块 / 执行调度的启发

**【原文证明】**：综述**没有**讨论动作块。
**【我的补充】**：把"线 4（执行调度）"与这篇的五类结合：

| 生成方式 | 典型块长 | 为什么 |
|---|---|---|
| 扩散（多步） | 长块（16–32 步） | 摊薄多步推理 |
| 分类 token | 短块或单步 | 单步便宜 |
| GMM | 短块 | 单步便宜 |

> **一个可检验的假设**：**动作块的长度与生成模型的推理步数正相关**——因为块是用来摊薄推理代价的。

### C. 对量化、缓存、压缩的启发

**【原文证明】**：综述提了推理代价但没展开压缩技术。
**【合理推测】**：五类模型的"压缩友好度"不同：
- 采样模型/GMM：参数少，压缩空间小；
- **扩散：多步共享同一网络 → 权重共享天然存在**，量化收益大；
- 分类模型：logits 维度 = 动作维 × 256 → **输出层巨大，量化收益大**。

**【待验证】**：不同生成范式的"量化敏感性"是否不同？

### D. 是否能用于轮式双臂机器人？

**【原文证明】**：综述的应用涵盖位姿、轨迹、位移、场景布局。
**【合理推测】**：轮式双臂的动作 = 底盘 + 双臂，**维度高且异构**；分类模型要为每个维度开 256 个 bin → 输出爆炸。**扩散/流匹配在这种高维异构动作上更有优势**（这也解释了为什么 π0/MAVP 用它）。

### E. 是否需要真实硬件？

| 目标 | 需求 | 可行性 |
|---|---|---|
| 复现五类模型之一 | 仿真 + 公开数据 | ✅ 容易 |
| 做横向对比 | 统一基准（如 Push-T） | ✅ 可行 |
| 真机 | 机器人 | ⚠️ |

### F. 能否在仿真中先复现？

**【我的判断】**：**非常适合**。五类模型都有现成实现（VAE/GAN/Diffusion/GMM 都是标准件），Push-T 这类任务数据量小。

### G. 本科阶段能否完成小规模实验？

**【我的判断】非常适合**：

> **题目**：在同一个 2D 多峰任务（如 Push-T 或双峰回归）上，对比 GMM / 分类 / 扩散三种生成模型在"多峰覆盖度、推理时间、样本效率"上的差异。

- 变量：生成范式；
- 指标：多峰覆盖率、延迟；
- 预期：【合理推测】GMM 最快但覆盖差、扩散最慢但覆盖好。

### H. 博士阶段能否进一步拓展？

三条线：
1. **移动 trade-off 曲线**（见 A）；
2. **块长与步数的联合优化**（见 B）；
3. **不同范式的量化敏感性**（见 C）。

## 三、四个可落地的研究点

### 研究点 #1：把"速度-表达力"曲线量化（我最推荐）

| 项目 | 内容 |
|---|---|
| **动机** | 综述只给定性描述，没有定量曲线 |
| **设计** | 同一任务、同一数据，实现 5 类模型，测（多峰覆盖率，延迟） |
| **指标** | 覆盖率、延迟、样本效率 |
| **价值** | 给"该选哪类"提供定量依据；**这是综述缺的图** |

### 研究点 #2：块长 × 步数的联合设计

| 项目 | 内容 |
|---|---|
| **动机** | 见 B：块长可能是为了摊薄步数 |
| **假设** | 最优块长 $\propto$ 推理步数 |
| **设计** | 二维扫描（步数 1/4/10/50 × 块长 1/4/16/32） |
| **指标** | 成功率、端到端延迟 |
| **价值** | 把"生成"与"调度"连起来（两个综述都没做） |

### 研究点 #3：不同范式的量化敏感性

| 项目 | 内容 |
|---|---|
| **动机** | 见 C |
| **设计** | 5 类模型各做 int8/int4，测质量下降 |
| **价值** | 给"压缩+生成"的组合提供依据 |

### 研究点 #4：EBM 的组合性用于多约束任务

| 项目 | 内容 |
|---|---|
| **动机** | 综述说 EBM 可组合性最强 |
| **设计** | 用能量相加实现"任务 + 避障 + 平滑"多约束 |
| **指标** | 约束满足率 |
| **价值** | 偏理论但有意思 |

## 四、一个具体案例：多峰分布下"取平均"的失败（经典教学例）

> [!warning] 案例性质
> 这是**为理解"多模态"构造的经典教学示例**（与综述 §II 的立论一致），不是原文实验。

**场景**：桌面上一个杯子挡在正中间，机器人要绕过去抓住后面的方块。

| 训练数据 | 内容 |
|---|---|
| 示范 A（40%） | 从左边绕 |
| 示范 B（40%） | 从右边绕 |
| 示范 C（20%） | 从上面绕 |

| 模型 | 会怎么做 |
|---|---|
| **单峰高斯 + MSE** | 输出"直着走"的平均动作 → **撞杯子** |
| **GMM（3 成分）** | 学到三个峰 → 随机选一个 → 成功 |
| **扩散** | 学整个分布 → 成功 |
| **分类（256 bin）** | 学到多峰 → 成功 |

**关键理解**：
- 失败原因不是"模型不够大"，而是**模型族的表达力不够**；
- **这就是为什么生成模型是模仿学习的必需品**。

## 六、复现时会踩的坑

| 坑 | 说明 | 建议 |
|---|---|---|
| **"多模态"歧义** | 指分布多峰还是多传感器 | 看上下文 |
| **五类边界模糊** | 流匹配归哪类 | 按"生成机制"归类 |
| **延迟测量** | 要控 batch、硬件 | 统一条件 |

## 八、一句话总结对我的价值

> **这篇综述把我零散读过的"动作生成"论文，统一成了"用五种方式表示一个多峰分布"。**
> 而它最有用的地方，是把**推理代价**写进了分类——这让我看清：**我做的加速研究，是在一条"表达力 vs 速度"的曲线上做文章**。
> 它没做的两件事，恰好是我的空间：
> ① **把这条曲线量化**（综述只有定性）；
> ② **把"生成步数"与"执行块长"联合优化**（三篇综述都没碰）。
