## 二、六个概念的五层解释

### 2.1 接地（Grounding）

1. **一句话**：让"说"和"做"对得上。
2. **类比**：一个人只会念菜谱（语言），从没下过厨（世界）。你让他"炒个蛋"，他可能说"先预热烤箱"——语法没错，但对这个厨房是错的。
3. **机器人例子**：LLM 说"用吸尘器吸掉"，但厨房里没有吸尘器、机器人也不会用。
4. **技术原理**：把语言的符号空间映射到"当前状态下的可行动作集合"。SayCan 用**可供性概率**做这个映射。
5. **与本文关系**：全文就是为了解决"不接地"。

### 2.2 可供性（Affordance）

1. **一句话**：环境"允许"你做什么。
2. **类比**：一扇门有把手 → 可供"拉"；没有把手 → 只能"推"。同一个动作，在不同环境里的可行性不同。
3. **机器人例子**：桌上有个海绵 → "拿海绵"可供性高；海绵在柜子里关着 → 可供性低。
4. **技术原理**：Gibson 的心理学概念，在机器人里通常被实现成"技能成功概率"或"可操作性评分"。
5. **与本文关系**：作者用**稀疏奖励 RL 的价值函数**来量化它——这是本文最实用的一步。

### 2.3 为什么"价值函数 = 可供性"

1. **一句话**：如果奖励只有"最后成功给 1"，那么价值函数就是"成功率"。
2. **类比**：一场只有输赢的比赛，赛前问"你赢的概率多大"——这就是价值。
3. **机器人例子**：$V(s)=0.8$ 表示"从这个状态开始执行这个技能，有 80% 概率成功"。
4. **技术原理**：$V^\pi(s)=\mathbb{E}[\sum \gamma^t r_t]$；当 $\gamma=1$、回合结束给 $r\in\{0,1\}$ 时，$V^\pi(s)=P(\text{成功}\mid s)$。
5. **与本文关系**：这是 SayCan 能用 RL 价值函数当可供性的理论依据（§2）。

### 2.4 任务接地 vs 世界接地

1. **一句话**：前者问"该不该做"，后者问"做不做得成"。
2. **类比**：你想喝水（该不该：该），但杯子在柜子最上层够不到（做不做得成：不成）。
3. **机器人例子**：指令"拿可乐"，LLM 给 "pick up coke can" 高分（该做），但可乐不在视野里 → 价值函数给低分（做不成）。
4. **技术原理**：$p(\ell_\pi\mid i)$ 与 $p(c_\pi\mid s,\ell_\pi)$ 两个概率，来自两个完全不同的模型。
5. **与本文关系**：**这两个概率相乘就是 SayCan。**

### 2.5 打分 vs 生成

1. **一句话**：不让模型"写答案"，而是让它"给选项打分"。
2. **类比**：考试从"论述题"改成"选择题"——答案一定在选项里，还能比较相对优劣。
3. **机器人例子**：技能库里只有 551 个描述，LLM 只需给这 551 个候选各打一个分。
4. **技术原理**：读 LLM 对每个候选序列的 log-prob（需要把候选放在固定 prompt 后面前向一次）。
5. **与本文关系**：这让"概率相乘"成为可能，也让计划可解析（表 2 中 Generative 基线 74% < 打分 84%）。

### 2.6 技能粒度 = 重规划粒度

1. **一句话**：技能切得越细，重规划越频繁；切得越粗，越容易跑偏。
2. **类比**：导航说"下一个路口左转"（细）vs "往北开 10 公里"（粗）。
3. **机器人例子**："拿海绵"是一个技能，执行完才重新规划；如果中途海绵掉了，规划器不知道。
4. **技术原理**：Algorithm 1 的循环粒度就是技能粒度。
5. **与本文关系**：作者没讨论粒度选择，但这**恰恰是"执行调度"的核心变量**（见 [[Paper_007_SayCan/05_科研启发与复现建议]]）。

## 三、公式逐个讲

### 公式 1：LLM 的任务接地概率

$$
p(\ell_\pi\mid i)
$$

**性质**：🟢 **原文使用**（§3）。

| 符号 | 含义 |
|---|---|
| $i$ | 用户指令 |
| $\ell_\pi$ | 技能 $\pi$ 的语言描述 |
| $p(\ell_\pi\mid i)$ | LLM 认为"这个技能是完成指令的合理下一步"的概率 |

**直观**：在"我洒了饮料"后面，LLM 更可能接"找一块海绵"而不是"打开抽屉"。
**怎么算**：把对话 prompt 喂给 LLM，读它对候选描述的 log-prob（必要时归一化）。
**数字例子**（教学示例）：假设候选有 3 个技能，LLM 给的相对概率是 0.7 / 0.2 / 0.1。注意这不是校准过的概率，只是相对分数。
**在流程中的位置**：图 1 的 P1、图 2 的 C。

---

### 公式 2：可供性（世界接地）

$$
p(c_\pi\mid s,\ell_\pi)
$$

**性质**：🟢 **原文使用**（§3），并明确"在稀疏奖励下等于价值函数"。

| 符号 | 含义 |
|---|---|
| $c_\pi$ | 技能 $\pi$ 成功完成的伯努利事件 |
| $s$ | 当前状态（图像） |

**直观**："如果我现在让它做 $\ell_\pi$，它能做成吗？"
**数字例子**：可乐在视野中央 → 0.9；可乐在关着的柜子里 → 0.1。
**在流程中的位置**：图 1 的 P2、图 2 的 D。

---

### 公式 3：组合分数与选择（★核心）

$$
\pi_n = \arg\max_{\pi\in\Pi}\ p(c_\pi\mid s_n,\ell_\pi)\cdot p(\ell_\pi\mid i,\ell_{\pi_{n-1}},\dots,\ell_{\pi_0})
$$

**性质**：🟢 **原文公式**（§3、Algorithm 1）。

**直观**：既"有用"又"做得成"的技能胜出。
**为什么相乘**：两个事件近似独立——"这个技能对不对"与"这个技能能不能成"；概率的联合 = 乘积。
**数字例子**（教学示例，教学构造，非作者实验）：

| 技能 | LLM 分数 | 可供性 | 乘积 |
|---|---|---|---|
| 拿海绵 | 0.7 | 0.9 | **0.63** ✅ |
| 拿可乐 | 0.2 | 0.8 | 0.16 |
| 用吸尘器 | 0.1 | 0.0 | 0.00 |

注意第三行：LLM 给了一点分（因为语义上"吸尘器能清理"），但可供性为 0 → 乘积为 0。**这就是"接地"如何否决 LLM 的幻觉。**

**在流程中的位置**：图 1 的 M1、图 2 的 E/F。

---

### 公式 4：分解假设（为什么可以相乘）

$$
p(c_i\mid i,s,\ell_\pi)\ \propto\ p(c_\pi\mid s,\ell_\pi)\cdot p(\ell_\pi\mid i)
$$

**性质**：🟢 **原文推导**（§3）。

**推导过程（作者的假设）**：
1. 若技能成功（$c_\pi=1$），它以 $p(\ell_\pi\mid i)$ 的概率推进任务；
2. 若技能失败（$c_\pi=0$），推进概率为 0；
3. 因此 $p(c_i\mid i,s,\ell_\pi)=p(c_\pi\mid s,\ell_\pi)\cdot p(\ell_\pi\mid i)+0$。

**直观**：要"真的推进任务"，必须**既选对又做成**。
**这个假设强在哪**：它假设"技能成功"与"技能是否正确"独立。现实中不完全成立（比如"正确的技能但执行到位"其实也依赖环境）。
**为什么仍然有效**：因为它在**排序**上足够好——表 2 的消融证明两个因子都不可省。
**数字例子**：若 $p(c_\pi)=0.9$、$p(\ell_\pi\mid i)=0.7$，则组合 = 0.63；若技能成功率只有 0.3，组合降到 0.21——**即使方向完全正确，做不成就等于没做**。

**在流程中的位置**：解释图 1 的 M1 为什么合理。

### 公式 5：价值函数的 TD 损失（背景公式）

$$
\mathcal{L}_{TD}(\theta)=\mathbb{E}_{(s,a,s')\sim\mathcal{D}}\left[R(s,a)+\gamma\,\mathbb{E}_{a^*\sim\pi}Q^\pi_\theta(s',a^*)-Q^\pi_\theta(s,a)\right]
$$

**性质**：🟢 **原文式**（§2，作为背景介绍）。

**直观**：让"当前估计"靠近"即时奖励 + 折扣后的下一状态估计"。
**与本文关系**：这是训练可供性函数的方法；作者强调在稀疏奖励 + 不折扣时，$Q$ 就是成功率。

---

### 公式 6：终止条件（我的整理）

$$
\text{循环直到 } \ell_{\pi_n}=\text{"done"}
$$

**性质**：🟡 原文 Algorithm 1 有，但没有写成公式。

**为什么重要**：**终止由 LLM 决定**，这是长程任务失败的主要来源（"过早终止"，§5.1 明确说 long-horizon 族的失败多由此而来）。
**数字例子**：指令"扔掉可乐并拿海绵"，LLM 可能只选了"扔掉可乐"就输出 done → 计划不完整。

## 四、符号总表

| 符号 | 含义 |
|---|---|
| $i$ | 用户指令 |
| $s$ | 状态 |
| $\Pi$ | 技能库 |
| $\pi$ | 技能（本身是策略） |
| $\ell_\pi$ | 技能的语言描述 |
| $c_\pi$ | 技能成功事件（伯努利） |
| $p(c_\pi\mid s,\ell_\pi)$ | 可供性 / 价值函数 |
| $p(\ell_\pi\mid i)$ | LLM 打分 |
| $n$ | 规划步索引 |
| $\gamma$ | 折扣因子 |
| $Q^\pi$ | 状态-动作价值 |

## 五、最容易混淆的三组概念

| 容易混淆 | 区别 | 记法 |
|---|---|---|
| **可供性 vs 成功率** | 在本文里等价（稀疏奖励 + 不折扣） | 但严格说"可供性"是更宽的概念 |
| **任务接地 vs 世界接地** | 前者管"对不对"，后者管"成不成" | "该不该" vs "能不能" |
| **打分 vs 生成** | 前者读概率，后者采样文本 | 打分才能相乘 |
