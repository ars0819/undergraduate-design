## 一、贡献的分级

### A. 最重要的贡献（只选 1 项）

> **一个六层的知识结构：理论 → 估计 → 输入 → 数据/提升函数 → 任务 → 平台，并在每层给出"该做什么、坑在哪"。**

为什么这算"贡献"：
- Koopman 的文献散在控制、软体、空中三个社区，术语不统一；
- 初学者最常见的困惑不是"算子是什么"，而是"**我该选什么提升函数、采什么数据**"；
- 这篇把后者放到了和前者的同等位置（§III-A、§III-B 独立成节）。

### B. 其他有价值的贡献

| 贡献 | 说明 |
|---|---|
| **配套教程代码**（KoopmanRobo） | 综述里少见，降低入门门槛 |
| **把"提升函数选择"独立成节** | 承认这是工程核心而非细节 |
| **应用按平台分五类** | 方便读者定位自己关心的领域 |
| **§VI 的四条开放问题** | 具体、可做，不是套话 |
| **同时讲 EDMD 与 HVOK** | 覆盖通用与软体两个主流 |

### C. 借鉴/整理的内容

| 内容 | 来源 |
|---|---|
| Koopman 算子理论 | Koopman 1931（[26]） |
| EDMD | Williams et al.（[27]） |
| HVOK | 软体机器人社区（[28]） |
| Koopman-MPC | 多篇（§III-C 引用） |
| 鲁棒 Koopman | §III-F 引用 |

### D. 不属于创新的部分

- 没有新的估计算法；
- 没有新的提升函数；
- 没有统一基准实验。

> [!important] 一句话总结
> **这篇的价值在"组织"和"降低门槛"，不在"提出新方法"。**

## 二、综述的四个评价维度

### ① 分类框架是否清晰可操作？

**评价：好。**

框架沿"一个问题从零到落地"的顺序展开：
```
想用 Koopman 做一个机器人任务
 ├─ 第 1 步：懂算子（§II-A）
 ├─ 第 2 步：从数据估出来（§II-B）
 ├─ 第 3 步：加上控制输入（§II-C）
 ├─ 第 4 步：采什么数据（§III-A）
 ├─ 第 5 步：选什么提升函数（§III-B）
 ├─ 第 6 步：做什么任务（§III-C/D/E/F）
 └─ 第 7 步：在什么平台上（§IV）
```
**优点**：这是"实现顺序"，不是"文献分类"。读者能照着做。
**不足**：§II-C（输入）与 §V-B（进阶输入）有内容重叠，容易让初学者困惑该读哪个。

### ② 是否覆盖关键缺口？

| 缺口 | 是否覆盖 | 评价 |
|---|---|---|
| 理论与工程的桥 | ✅ §III-A/B | 好 |
| 输入处理 | ⚠️ §II-C 偏简 | **偏弱**（机器人最关键） |
| 约束处理 | ❌ 只在开放问题里提 | 缺 |
| 与深度学习的结合 | ⚠️ 提到但不深 | 偏弱 |
| 与 VLA/大模型 | ❌ 无 | 超出范围，但**对我是缺口** |

### ③ 是否给出可执行建议？

**部分给出。** 例如：
- 数据采集：§III-A 讨论了激励设计（需要足够丰富的输入）；
- 提升函数：§III-B 给了几类选择（多项式、RBF、物理先验）；
- 但**没有给出"什么任务选什么"的决策表**——这是可以改进的地方。

### ④ 开放问题是否具体？

**相当具体**（§VI）：

| 问题 | 具体在哪 |
|---|---|
| 约束进 Koopman 空间 | 明确指出"约束在提升后可能变非凸" |
| 混合动力学 | 点明接触/切换系统是开放问题 |
| 提升后的不确定性 | 提出"高斯经非线性提升是否仍高斯"这一可检验问题 |
| 优化适定性 | 指出递归可行性难点与代价设计无定论 |

**这四条都可以直接做成博士课题。**

## 三、核心链条：一句话讲清 Koopman 的逻辑

```text
非线性系统 x_{t+1} = T(x_t)
      ↓ 选一组可观测量 Ψ
线性系统 z_{t+1} = K z_t,   z = Ψ(x)
      ↓ 在线性空间里用线性工具
LQR / MPC / 观测器 / 谱分析
      ↓ 但有两个前提
① 子空间在 K 下不变（实际只能近似）
② K 要能从数据估出来（EDMD）
```

**整篇综述就是围绕这两个前提展开的**：
- 前提 ① → §III-B（提升函数）、§V-C（构造）；
- 前提 ② → §II-B（EDMD/HVOK）、§III-A（数据采集）。

## 四、与其它"线性化"路线的对比（我的整理）

| 路线 | 怎么做 | 有效范围 | 代价 |
|---|---|---|---|
| **工作点线性化** | 泰勒展开一阶 | 局部 | 远离工作点失效 |
| **反馈线性化** | 用控制抵消非线性 | 依赖精确模型 | 模型误差敏感 |
| **Koopman** | 换可观测量，全局线性 | 全局（近似） | 维度升高、提升函数要设计 |
| **神经 ODE / 世界模型** | 用网络学动力学 | 数据覆盖范围 | 不保证线性、不可解释 |

> 这张表是**我的整理**，不是原文的表格。

## 五、方法层面的疑点清单（对综述的质疑）

1. **§II-C 输入处理太薄**：机器人没有输入就没法用，这一节应该更厚。
2. **没有统一基准**：读者无法判断"哪种提升函数在哪个任务上更好"。
3. **与深度学习的关系模糊**：神经网络提升函数（如深度 Koopman）只被提及，没有系统比较。
4. **没有讨论失败案例**：综述通常只讲成功，缺少"什么时候 Koopman 不work"的诚实讨论。

## 六、把综述浓缩成一张"决策树"（我的整理）

```text
你的系统是非线性的，想用线性工具？
 ├─ 动力学光滑、状态维数中等 → 可以试 Koopman
 │    ├─ 有仿真模型 → 用模型生成数据 + EDMD
 │    ├─ 只有实测数据 → 注意激励设计（§III-A）
 │    └─ 软体/高维柔性 → 优先考虑 HVOK
 ├─ 有接触/切换 → 【开放问题】目前不成熟
 └─ 需要严格约束保证 → 【开放问题】约束进 Koopman 空间仍难
```

> 这张决策树是我根据 §VI 的开放问题反推的，**原文没有这样画**。
