## 一、术语表（按在论文中出现的顺序）

| 英文术语 | 中文 | 一句话解释 | 在本文中的角色 |
|---|---|---|---|
| Vision-Language-Action model (VLA) | 视觉-语言-动作模型 | 输入图像和语言，直接输出机器人动作的端到端模型 | 本文的研究对象 |
| Vision-Language Model (VLM) | 视觉语言模型 | 能同时处理图像和文字的模型（如 LLaVA） | VLA 的骨干 |
| Autoregressive generation | 自回归生成 | 一个一个往外吐 token，每吐一个就把已吐的接回去继续算 | RT-2/OpenVLA 慢的原因 |
| Action tokenization | 动作 token 化 | 把连续动作值切成 256 个格子，变成整数 ID | 本文要替代的做法 |
| Discretization / binning | 离散化 / 分箱 | 把连续数映射到有限个格点 | token 化的实现手段 |
| Diffusion Policy (DP) | 扩散策略 | 用扩散模型（DDPM）生成动作序列的策略网络 | 本文的动作头 |
| DDPM | 去噪扩散概率模型 | 训练时学"加了多少噪声"，推理时从纯噪声开始逐步去噪 | 动作头的数学基础 |
| Denoising step | 去噪步 | 扩散推理中的一次迭代 | 决定精度与速度的关键超参（原文未给） |
| LoRA | 低秩适配 | 冻结原权重，只训练一个很小的低秩旁路矩阵 | 参数高效微调（占 5.0%） |
| Re-parameterization | 重参数化 | 把训练时的两个矩阵合并成一个，推理时零开销 | 提速技巧 |
| Adaptive pooling | 自适应池化 | 不管输入多长，都压成固定长度 | 让变长序列能接 MLP |
| LayerNorm | 层归一化 | 对每个样本的特征维度做标准化，稳定训练 | 池化后使用 |
| Proprioceptive state | 本体状态 | 机器人自己的关节角度、夹爪开合等 | 与视觉特征拼接 |
| Action chunking | 动作分块 | 一次预测多步动作，连续执行 | 图 2 的 $a^0\cdots a^t$（细节未给） |
| End-effector / Cartesian action | 末端执行器 / 笛卡尔动作 | 用 $x,y,z$ + 欧拉角描述夹爪位姿，而非关节角 | 本文的 7 维动作 |
| Success rate | 成功率 | 任务完成的试验比例 | 全部实验的唯一指标 |
| Multi-task learning | 多任务学习 | 一个模型学多个任务 | 本文所有实验都是多任务设定 |
| Few-shot / data efficiency | 少样本 / 数据效率 | 用很少的示范就能学会 | 本文核心主张之一 |

## 二、八个概念的"五层解释"

> 五层 = ① 一句话直观 ② 生活类比 ③ 机器人例子 ④ 技术原理 ⑤ 与本文创新的关系。

### 2.1 VLA（视觉-语言-动作模型）

1. **一句话**：一个模型，看见画面、听懂人话、直接输出动作。
2. **类比**：驾校教练坐在副驾，看到路况（图像）、听到"前面左转"（语言）、直接动方向盘（动作）。
3. **机器人例子**：相机看到桌上有个网球，听到"把网球放进盒子里"，输出机械臂末端的移动增量。
4. **技术原理**：通常 = 视觉编码器 + 语言模型 + 动作解码器。训练方式是模仿学习（behavior cloning）：给 $(观测, 指令, 动作)$ 三元组，最小化预测动作与示范动作的差异。
5. **与本文的关系**：TinyVLA 就是一个 VLA，但它把"动作解码器"换成了扩散头。

### 2.2 自回归动作 token 化（本文要打倒的对象）

1. **一句话**：把动作当成"外语单词"，让语言模型一个词一个词地说出来。
2. **类比**：让你描述一个三位小数 3.14159，但只允许用整数报数——你只能一位一位念"3、1、4、1、5、9"，而且每念一位都要重新想一遍前面念了什么。
3. **机器人例子**：7 维动作（3 位置 + 3 旋转 + 1 夹爪），每一维被切成 256 个 bin，变成 7 个 token。机器人要等模型吐完 7 个 token 才能动。
4. **技术原理**：
   - 分箱：$v \in [-1,1] \mapsto \text{bin}(v) \in \{0,\dots,255\}$，常用 256 或 1024 个 bin；
   - 训练：交叉熵，预测每个 bin 的类别；
   - 推理：自回归解码，第 $d$ 个 token 的生成依赖前 $d-1$ 个 token。
   - 问题：① 量化误差；② 每个 bin 都要有足够样本，小数据下学不好；③ 串行解码慢。
5. **与本文的关系**：论文 §I 把"自回归动作 token 生成"列为两大延迟来源之一，并在 §III-B 明确说"不用 token 化，改用 DP 头"。

### 2.3 扩散策略头（Diffusion Policy Head）

1. **一句话**：先随便猜一个动作（纯噪声），然后一点点改，改 $K$ 次就得到像样的动作。
2. **类比**：雕塑。一开始是一块乱石（噪声），每次凿掉一点多余的部分，最后出现人像（动作）。
3. **机器人例子**：给定"把网球放进盒子"的条件，从一团随机数出发，第 1 次去噪得到大概朝右，第 5 次得到具体坐标，第 10 次得到平滑的抓取位姿。
4. **技术原理**：
   - 训练：取真实动作 $a_0$，随机选步数 $k$，加噪得到 $a_k$，让网络预测所加的噪声 $\varepsilon$；
   - 推理：从 $a_K \sim \mathcal{N}(0,I)$ 开始，用同一个网络迭代 $K$ 次，逐步得到 $a_0$；
   - 条件 $c$（来自 VLM 特征）在每一步都作为输入，这叫**条件扩散**。
5. **与本文的关系**：**这就是本文的核心创新**。它把"7 次大模型前向"变成"1 次大模型前向 + $K$ 次小网络前向"。

### 2.4 LoRA（低秩适配）

1. **一句话**：不动原来的大矩阵，只在旁边挂两个很薄的矩阵当"便签"，训练时只改便签。
2. **类比**：一本厚教科书的正式内容不许改（冻结），但你可以贴便利贴（LoRA）。考试时把便利贴的内容抄进正文（重参数化），书就一本了。
3. **机器人例子**：7B 的 VLM 有几十亿参数，全量微调会"忘掉"看图说话的能力。LoRA 只改 5% 的参数，语义能力保住，动作能力学进来。
4. **技术原理**：$W \in \mathbb{R}^{d\times k}$ 冻结，新增 $B\in\mathbb{R}^{d\times r}$、$A\in\mathbb{R}^{r\times k}$，$r \ll \min(d,k)$。前向时 $Wx + BAx$。参数量从 $dk$ 降到 $r(d+k)$。
5. **与本文的关系**：§III-B 明确说"可训练参数只占整个 Transformer 的 5.0%"，并且加在 Q/K/V 上。

### 2.5 重参数化（Re-parameterization）

1. **一句话**：训练时两条路，训完合成一条路。
2. **类比**：装修时用脚手架（LoRA 分支），装修完拆掉脚手架，房子还是那间房子。
3. **机器人例子**：训练时每层注意力要算 $W_0x + BAx$（两次矩阵乘），推理时先算 $W' = W_0 + BA$，之后只算 $W'x$（一次）。
4. **技术原理**：矩阵加法可交换且线性，$W_0 x + BAx = (W_0 + BA)x$。前提是 $B$、$A$ 的形状能相加（这里 $BA$ 与 $W_0$ 同形）。
5. **与本文的关系**：§III-B 第 1 段末："we apply re-parameterization techniques ... thereby enhancing inference speed"。**注意：这是推理加速的一部分，但论文没有单独量化它贡献了多少毫秒。**

### 2.6 自适应池化 + LayerNorm

1. **一句话**：把长短不一的句子压成同样长的一段，再做个标准化。
2. **类比**：不管来多少人开会，最后只能派 1 个代表发言（池化），发言前先把情绪调平稳（LayerNorm）。
3. **机器人例子**：指令有时 5 个词、有时 20 个词，LLM 输出的 token 数就不同；但后面的 MLP 只吃固定维度向量，所以必须先压成定长。
4. **技术原理**：自适应池化（adaptive average pooling）把长度 $N$ 的序列分成固定 $M$ 段取平均；LayerNorm 对特征维做零均值一方差归一化。
5. **与本文的关系**：§III-B 第 2 段："To handle the inherent variability in input sequence lengths, we employ an adaptive pooling layer followed by layer normalization, producing fixed and compact feature representations."
   → **这是论文里被一笔带过、但复现时最容易出错的一步**：池化到多少维？取最后一个 token 还是平均？原文没说。

### 2.7 动作块（Action Chunking）与重规划频率

1. **一句话**：一次想好接下来几步怎么走，而不是每走一步都想一次。
2. **类比**：下棋时一次想好后面 5 步（动作块），而不是每落一子都重新长考。
3. **机器人例子**：模型一次输出 16 步动作，机器人连续执行 16 步（约 0.5 秒），然后再拍一张照重新预测。执行期间不再推理，所以推理慢一点也能接受。
4. **技术原理**：
   - 动作块长度 $T$：一次预测多少步；
   - 重规划频率：多久重新推理一次；
   - 二者与推理延迟 $\tau$ 的关系决定了有效控制频率：$f_{\text{eff}} \approx \min\left(\frac{1}{\tau},\ \frac{1}{T\cdot \Delta t}\right)$ 其中 $\Delta t$ 是单步执行时间。
   - 如果 $T\Delta t \gg \tau$，推理延迟被"摊薄"，系统看起来很快；
   - 如果 $T$ 太大，开环执行太久，遇到扰动就漂移。
5. **与本文的关系**：**这是本文最大的信息缺口**。图 2 画了 $a^0\cdots a^t$，暗示存在动作块，但**$T$ 是多少、执行几步后重规划，原文完全没写**。你无法从论文判断它是"每步都推理"还是"推理一次执行一段"。

### 2.8 本体状态（Proprioceptive State）

1. **一句话**：机器人对"自己身体现在什么姿势"的感觉。
2. **类比**：闭着眼睛你也知道自己手举多高——这就是本体感觉。
3. **机器人例子**：7 个关节的角度、夹爪开合度。
4. **技术原理**：一个低维向量 $s_t$，与视觉语义特征拼接后一起送进 MLP。它提供了"绝对尺度"信息，而图像只能提供"相对位置"。
5. **与本文的关系**：§III-B："these normalized features are subsequently concatenated with the robot's proprioceptive state vector"。**维度原文未给。**

## 三、公式逐个讲

> 说明：TinyVLA 全文**只有一个显式公式**（LoRA 分解）。扩散部分只有文字描述。所以下面我把"原文公式"和"必须补的标准公式"分开标注，绝不把标准公式说成作者的。

### 公式 1（原文唯一公式）：LoRA 的低秩分解

$$
W = W_0 + \Delta W = W_0 + BA, \qquad B \in \mathbb{R}^{d\times r},\ A \in \mathbb{R}^{r\times k},\ r \ll \min(d,k)
$$

**① 出处**：§III-B 第 1 段（原文写法：$W_0 + \Delta W = W_0 + BA$，并说明 $r$ 远小于 $d$ 或 $k$）。

**② 每个变量**

| 符号 | 含义 | 典型取值（本文未给，此处是通用量级） |
|---|---|---|
| $W_0$ | 预训练好的原始权重矩阵，**冻结不动** | $d\times k$ |
| $\Delta W$ | 需要学习的增量 | 同形 |
| $B$ | 低秩矩阵之一（"降维"） | $d \times r$ |
| $A$ | 低秩矩阵之二（"升维"） | $r \times k$ |
| $r$ | 秩（瓶颈维度），控制 LoRA 容量 | 常见 4–64（本文未给） |
| $d, k$ | 输入/输出维度 | 由模型决定 |

**③ 直观含义**：本来要学 $d\times k$ 个数（可能上千万），现在只学 $r(d+k)$ 个数。当 $d=k=4096$、$r=16$ 时，原来 1677 万，现在 13 万，**约 128 倍**的参数节省。

**④ 为什么这样设计**：作者相信"微调带来的改变是低秩的"——即从"通用视觉语言模型"到"机器人策略"，需要的改变集中在一个低维子空间里。这个假设来自 LoRA 原论文（[29]），TinyVLA 只是使用者。

**⑤ 数字例子**（教学示例，非作者实验）：
设某注意力层 $W_0$ 是 $4096\times4096$。
- 全量微调：$4096\times4096 = 16{,}777{,}216$ 个参数。
- LoRA($r=16$)：$4096\times16 + 16\times4096 = 131{,}072$ 个参数。
- 比例：$131072 / 16777216 = 0.78\%$。
- 论文说整体可训练参数占 5.0%（§III-B），比单层 0.78% 高，是因为**Adapter、MLP、扩散头也是全参数训练的**。这一点常被误读为"LoRA 占 5%"，实际是"整个可训练部分占 5.0%"。

**⑥ 在流程中的位置**：图 1 的 B2、B6 节点；图 3 的 T2、T6 节点。

**⑦ 与其他公式的联系**：公式 5（重参数化）就是它训练后的合并操作。

### 公式 2（原文未写，标准 DDPM）：前向加噪

$$
a_k = \sqrt{\bar\alpha_k}\, a_0 + \sqrt{1-\bar\alpha_k}\, \varepsilon, \qquad \varepsilon \sim \mathcal{N}(0, I)
$$

**① 出处**：**原文没有这个公式**。依据是原文 §III-B "DP formulates robot policies using Denoising Diffusion Probabilistic Models (DDPMs) [35] which predicts the noise instead of direct actions"，公式来自 DDPM 原论文（Ho et al., 2020，即本文参考文献 [35]）。

**② 每个变量**

| 符号 | 含义 |
|---|---|
| $a_0$ | 干净的（真实示范）动作 |
| $a_k$ | 加了 $k$ 步噪声后的动作 |
| $k$ | 扩散步索引，$k=1,\dots,K$ |
| $\bar\alpha_k$ | 累积保留系数，$\bar\alpha_k = \prod_{i=1}^{k}(1-\beta_i)$，单调递减 |
| $\beta_i$ | 第 $i$ 步的噪声强度（噪声调度） |
| $\varepsilon$ | 标准高斯噪声 |

**③ 直观含义**：$k$ 越大，动作越像噪声。$k=0$ 是干净动作，$k=K$ 几乎纯噪声。$\sqrt{\bar\alpha_k}$ 和 $\sqrt{1-\bar\alpha_k}$ 是"保留原信号"和"掺入噪声"的比例，两者平方和为 1（能量守恒）。

**④ 为什么这样设计**：让"加噪"变成一步到位的闭式公式（不用迭代 $k$ 次），训练时可以随机采样任意 $k$，效率高。

**⑤ 数字例子**（教学示例）：设 $\bar\alpha_k = 0.5$，真实动作 $a_0 = 0.8$，采样噪声 $\varepsilon = -0.3$：
$$a_k = \sqrt{0.5}\times 0.8 + \sqrt{0.5}\times(-0.3) = 0.707\times0.8 - 0.707\times0.3 = 0.566 - 0.212 = 0.354$$
即"干净值 0.8 被拉向 0，变成 0.354"，因为混进了一半噪声。

**⑥ 在流程中的位置**：图 3 的 T4 节点（训练阶段）。

**⑦ 与其他公式的联系**：公式 3 用它构造监督信号；推理时反过来用（从 $k=K$ 到 $0$）。

### 公式 3（原文未写，标准 DDPM）：训练损失

$$
\mathcal{L} = \mathbb{E}_{a_0,\ \varepsilon,\ k}\left[\ \left\| \varepsilon - \varepsilon_\theta\!\left(a_k,\ k,\ c\right) \right\|_2^2\ \right]
$$

**① 出处**：**原文未写**。原文只说 "predicts the noise instead of direct actions"（§III-B）。这是 DDPM 的标准简化目标（预测噪声 $\varepsilon$ 而非预测 $a_0$）。

**② 每个变量**

| 符号 | 含义 |
|---|---|
| $\varepsilon$ | 真实加入的噪声 |
| $\varepsilon_\theta(a_k, k, c)$ | 网络预测的噪声，$\theta$ 是参数 |
| $c$ | 条件（本文中 = VLM 特征 + 本体状态经 MLP 得到的嵌入） |
| $\|\cdot\|_2^2$ | 平方 L2 范数（逐元素平方和） |
| $\mathbb{E}$ | 对数据、噪声、步数取期望 |

**③ 直观含义**：给网络看"脏动作 + 步数 + 条件"，让它猜"你被加了什么噪声"。猜得越准，说明它越懂"在这个条件下，什么样的动作是干净的"。

**④ 为什么这样设计**：直接回归 $a_0$ 会让网络学"平均动作"（多峰分布被平均成单峰）；预测噪声等价于学得分函数（score），能保留多模态性。这是扩散模型相比 MSE 回归的核心优势。

**⑤ 数字例子**（教学示例）：7 维动作，某一步真实噪声 $\varepsilon=[0.1,-0.2,0.3,0,0.5,-0.1,0.2]$，网络预测 $\hat\varepsilon=[0.12,-0.18,0.25,0.05,0.45,-0.05,0.2]$。
误差平方和 $=(0.02)^2+(0.02)^2+(0.05)^2+(0.05)^2+(0.05)^2+(0.05)^2+(0)^2 = 0.0004+0.0004+0.0025\times4 = 0.0108$。
损失就是这个值的期望。

**⑥ 在流程中的位置**：图 3 的 T5 节点。**这是整个训练阶段唯一被优化的目标**。

**⑦ 与其他公式的联系**：公式 2 构造输入，公式 3 定义目标，推理时用同一个 $\varepsilon_\theta$ 反向迭代。

### 公式 4（原文为文字描述，无公式）：条件嵌入

$$
c = f_{\text{MLP}}\Big(\big[\ \text{LayerNorm}(\text{AdaPool}(h))\ ;\ s_t\ \big]\Big)
$$

**① 出处**：§III-B 第 2 段用文字描述了三步：adaptive pooling + layer normalization → 拼接本体状态 → 3 层 MLP。**原文没有写公式**，这个式子是我不改变含义的形式化。

**② 每个变量**

| 符号 | 含义 |
|---|---|
| $h$ | VLM 输出的多模态隐状态序列（变长） |
| $\text{AdaPool}(\cdot)$ | 自适应池化，输出定长 |
| $s_t$ | 本体状态向量 |
| $[\cdot;\cdot]$ | 向量拼接 |
| $f_{\text{MLP}}$ | 3 层多层感知机 |
| $c$ | 条件嵌入，送入扩散头 |

**③ 直观含义**：把"我看到的世界"压成一个向量，再接上"我自己现在的姿势"，合成一句"当前局势摘要"，交给动作头。

**④ 为什么这样设计**：扩散头需要的是**低维、稳定、定长**的条件向量，而不是几千个 token。池化降低维度、LayerNorm 稳定尺度、MLP 做非线性融合。

**⑤ 数字例子**（教学示例，维度为假设）：$h$ 是 $512\times 2048$（512 个 token，每个 2048 维）→ 池化成 $1\times2048$ → 拼接 14 维本体状态 → $2062$ 维 → MLP 降到 $256$ 维 → $c$。

**⑥ 在流程中的位置**：图 1 的 B7-B10；图 2 的 R1-C1-M1。

**⑦ 与其他公式的联系**：它是公式 3 中条件 $c$ 的来源；没有它，扩散头就"看不见"指令和图像。

### 公式 5（原文未写，工程恒等式）：重参数化合并

$$
W' = W_0 + BA \quad\Longrightarrow\quad y = W'x \ \ \text{（替代）}\ \ y = W_0 x + BAx
$$

**① 出处**：§III-B 第 1 段文字："we apply re-parameterization techniques to integrate the LoRA module seamlessly into the standard language model"。

**② 变量**：同上，$W'$ 是合并后的权重。

**③ 直观含义**：两个矩阵乘可以合并成一个，因为矩阵乘法对加法有分配律。

**④ 为什么有效**：推理时少一次矩阵乘、少一次内存读取（$B$、$A$ 两个小矩阵的读写），对延迟敏感的场景有意义。

**⑤ 数字例子**（教学示例）：原来算 $W_0x$（$4096\times4096$ 乘 $4096$ 维）需要约 1678 万次乘加；加上 $BAx$ 要再算 $B(Ax)$：$4096\times16$ + $16\times4096$ = 13 万次。虽然只多 0.8%，但多了一次 kernel 启动和内存访问，在 GPU 上可能造成可观的固定开销。合并后这些全部消失。

**⑥ 在流程中的位置**：图 3 的 T7 → I1 之间。

**⑦ 与其他公式的联系**：公式 1 的收尾动作。

### 公式 6（我的推导，用于理解表 IV）：加速比分解

$$
S = \frac{T_{\text{AR}}}{T_{\text{diff}}} \approx \frac{D\cdot \tau_{\text{LM}} + \tau_{\text{enc}}}{K\cdot \tau_{\text{den}} + \tau_{\text{LM}} + \tau_{\text{enc}}}
$$

**① 出处**：**这是我为了解释表 IV 而写的分析式，不是原文公式。** 依据：§I 说自回归要"为每个自由度重复推理"，§V-C 说扩散头"avoids the computationally expensive autoregressive generation"。

**② 变量**

| 符号 | 含义 |
|---|---|
| $D$ | 动作维度（本文 7） |
| $\tau_{\text{LM}}$ | 一次大模型前向的时间 |
| $\tau_{\text{enc}}$ | 视觉编码 + 条件构造时间 |
| $\tau_{\text{den}}$ | 一次去噪网络前向时间 |
| $K$ | 去噪步数 |
| $T_{\text{AR}}, T_{\text{diff}}$ | 两条路线的总延迟 |

**③ 直观含义**：自回归的代价是 $D$ 倍的大模型前向；扩散的代价是 1 次大模型前向 + $K$ 次小网络前向。只要 $\tau_{\text{den}} \ll \tau_{\text{LM}}$，扩散就快。

**④ 为什么有用**：它解释了表 IV 的两个事实：
- 换小骨干：$\tau_{\text{LM}}$ 变小，但 $D$ 倍的结构没变 → 292→140 ms（约 2×）；
- 换解码方式：$D\tau_{\text{LM}}$ 变成 $K\tau_{\text{den}}$ → 140→14 ms（约 10×）。

**⑤ 数字例子**（教学示例，用表 IV 反推）：
设 7B 模型 $\tau_{\text{LM}}\approx 40$ ms（292/7 ≈ 41.7，假设 7 步解码、忽略 KV cache 加速）。
设 1B 模型 $\tau_{\text{LM}}\approx 19$ ms（140/7 = 20）。
TinyVLA 14 ms ≈ 1 次 1B 前向（约 10–19 ms 含编码）+ $K$ 次小网络去噪（每次 <1 ms）。
→ **反推：$K$ 大概在 5–10 的量级**。但这只是我的估算，**原文未给 $K$**。

**⑥ 在流程中的位置**：解释表 IV 与图 1 时使用。

**⑦ 与其他公式的联系**：它是公式 2、3 的"性能侧面"——同一个数学对象，两种成本结构。

## 五、最容易混淆的三组概念

| 容易混淆 | 区别 | 一句话记法 |
|---|---|---|
| **扩散策略 vs 扩散模型** | 扩散模型是生成图像的；扩散策略是把扩散用在"动作序列"上的策略网络 | "同一个数学，不同的输出对象" |
| **LoRA 参数占比 5% vs 全模型可训练 5.0%** | 论文说 5.0% 是"整个 Transformer 的可训练参数"，包含 Adapter 等 | 别把 5% 全算给 LoRA |
| **动作块长度 $T$ vs 扩散步数 $K$** | $T$ 是"一次预测几步动作"，$K$ 是"去噪迭代几次" | $T$ 管执行，$K$ 管生成；两者都可变慢 |
