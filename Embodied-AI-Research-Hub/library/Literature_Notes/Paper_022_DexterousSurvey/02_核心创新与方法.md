## 三、三条开放挑战（原文核心）

### 挑战 1：高质量多指数据稀缺

| 具体问题 | 原文表述要点 |
|---|---|
| 信息熵低 | 交互数据本身"低信息熵" |
| 仿真有 gap | 摩擦建模、可变形物体难模拟 |
| 人类数据不匹配 | 运动学/动力学差异 |
| 多数数据集是夹爪的 | 高 DoF 多指数据集少 |
| **缺力/触觉** | 关键反馈缺失 |
| **控制频率低** | 数十毫秒级，对精细操作太慢 |

> [!tip] 我对"信息熵低"的理解
> 灵巧操作的**大部分时间手是静止或微动的**，真正有信息的是"接触瞬间"的那几毫秒。所以十分钟的视频里，**有效样本可能只有几秒**——这就是"低信息熵"。

### 挑战 2：静态学习框架不鲁棒

| 具体问题 | 说明 |
|---|---|
| 学完就固定 | 不能在学习过程中被人动态纠正 |
| 人类干预是"弱耦合离散信号" | 只能表达"好/不好"，**表达不了"纠正多少"** |
| 作者的建议 | 利用**人体手臂末端刚度**这类连续信号 |

> **这条我认为最有洞察**：它指出了 RLHF 式二值反馈的根本局限——**"对/错"丢掉了"程度"信息**。

### 挑战 3：端到端泛化差

| 具体问题 | 说明 |
|---|---|
| 任务耦合 | 端到端把所有事混在一起 |
| 缺可解释性 | 失败难诊断 |
| 长序列需分层 | 低层技能库 + 中层技能生成 + 高层 VLM 规划 |
| **现有分层少涉及灵巧手与力觉** | ← 这是缺口 |

## 五、疑点清单

1. **"三条挑战"是作者观点**：有说服力，但非穷尽（比如"硬件成本"没算进去）。
2. **对触觉的讨论偏浅**：只说要"多点接触 + 力反馈"，没深入传感器。
3. **对 VLA 着墨少**：只在分层里提 VLM 规划；没有讨论"VLA 能不能用灵巧手数据"。
4. **未量化**：三种数据范式的成本/效率没有数字对比。
5. **文献覆盖**：偏 2023–2025，早期经典方法只提了名字。

## 六、把综述浓缩成一句可操作的话

```text
做灵巧操作研究之前，先问三个问题：
 1. 我的数据从哪来？（仿真 / 人类 / 遥操作）各自的坑我填了吗？
 2. 我的学习框架能接受"人的动态纠正"吗？还是学完就固定？
 3. 我是端到端还是分层？如果分层，低层技能库覆盖够吗？

再问一个作者没问、但我关心的：
 4. 我的系统延迟是多少？控制频率够吗？（数十毫秒对精细操作太慢）
```

**前三个问题来自这篇综述，第四个来自我自己的加速视角。**
