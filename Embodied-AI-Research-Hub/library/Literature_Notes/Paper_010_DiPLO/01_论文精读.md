# P010 · DiPLO 论文精读

> [!abstract] 一句话先给你
> **人形机器人要"既能走又能拿"，DiPLO 把它拆成"高层扩散规划器 + 低层 RL 追踪器"：规划器用 29 段（2.7 分钟！）人体动捕重定向数据预训练，然后做两步后训练——先用 SD:DPO 把"必须看运动学参考"这个依赖去掉，再用 DA:PPO 把"任务成功率"提上来。结果 pick-carry-place 的任务成功率从 **51.9% → 98.8%**，并在 Unitree G1 真机上零微调跑通。**

## 二、三种长度的摘要

### 2.1 30 秒摘要（约 160 字）

人形机器人做"走+拿"很难：数据少、要平衡、还要协调。DiPLO 把问题拆成两半：一个扩散规划器出"全身+物体的动作块"，一个 RL 追踪器负责执行。关键在两个后训练阶段：**SD:DPO** 用"带运动学参考的老师"蒸馏"只有状态和目标的学生的去噪预测"，把对参考轨迹的依赖去掉；**DA:PPO** 用最大熵 RL 直接优化任务成功率。pick-carry-place 从 51.9% 提到 98.8%，并在 G1 真机上零微调部署。

### 2.2 3 分钟摘要（约 500 字）

**问题。** 人形移动操作要求协调行走、平衡与物体交互。从人类动捕数据学是好办法，但数据极少（本文只有 **29 段、2.7 分钟**），而且重定向出来的运动**动力学不可行**（不满足接触与力矩约束）。

**方法。** 架构是"规划器-追踪器"：
- **规划器** $G_\phi$：输入状态历史、目标物体位姿、**可选的 IK 重定向参考**，输出 $n$ 帧"机器人+物体"的联合运动块。用 DiT 做去噪器，**欧氏特征与 SO(3) 旋转分开扩散**（旋转用 IGSO(3) 各向同性噪声）。
- **追踪器** $\pi_\theta$：50 Hz，接收观测、上一动作、以及规划块在 $\{1,2,4,8\}$ 帧偏移处的参考特征，输出**对参考关节位置的残差** $a_j$，$q^{PD}_j=q^{ref}_j+a_j$ 交给 PD 控制器。

**数据构造（这是被低估的一步）。** 原始 29 段 → 用 **SBTO（采样式轨迹优化）**在扰动初始条件下反复求解，得到**动力学可行**的变体 **898 段** → 再用**矢状面镜像 + 箱子四分之一转对称**增广到 **7,184 段**。表 I 显示：两种增广都用时效果最好（100% 存活、96.4% 成功），只用一种或不用都明显更差。

**两个后训练阶段（本文的核心）。**
1. **SD:DPO（自蒸馏）**：预训练时虽然以 50% 概率把参考替换成空 token，但**部署时不给参考，存活率会掉**（学生 57.7% vs 老师 96.5%）。原因是规划/追踪误差会把系统带到训练数据没覆盖的状态。于是：学生在环境里自己 rollout，把产生的计划存进 buffer；对同一个带噪计划，**老师（看参考）和学生（不看参考）各去噪一次**，学生匹配老师的预测（式 17）。这样把"参考提供的指导"蒸馏进了"只看状态+目标"的学生。
2. **DA:PPO（扩散增强 PPO）**：把去噪的每一步当成一个决策（DA-MDP），奖励只在最后一步（$k=1$，真正执行时）给，通过软 Bellman 递推把奖励**传播到所有去噪步**；同时用"反向核与正向核的对数比"作为正则项（最大熵），鼓励多样性。追踪器全程冻结。

**结果。**
- **Pick-carry-place**：预训练 51.9% → +DA:PPO 96.4%（表 I）；学生 + SD:DPO 55.1% → + DA:PPO **98.8%**（表 V）。
- **Kick**：34.4% → 68.1%；**Push/Pull**：23.3% → 52.7%。
- **泛化**：在极坐标网格上（半径 0.5–5 m、4 个朝向）目标位置远超训练集（最远演示仅 1.9 m），达到 **~100% 存活、88% 成功率**。
- **不经蒸馏的对比**：No-prior 模型（完全不用参考预训练）即使微调也只有 74.1% 存活 / 67.0% 成功——**说明"强先验预训练 + 蒸馏"比"直接不接地"好得多**。

**结论。** 人形移动操作可以用"少量人类动作 → 物理可行化 → 强先验预训练 → 两步后训练"这条流水线做出来，而且**每一步都有消融支撑**。

### 2.3 一句话核心创新

> **把"任务先验"当作一种"只在训练时可用的特权信息"，用自蒸馏把它迁移进"部署时只看状态与目标"的规划器，再用 DA:PPO 把任务成功率拉满——两步各解决一个不同的问题，缺一不可。**

## 三、用大白话回答六个问题

### ① 想解决什么问题？

人形机器人"边走边拿东西"，而且只有 2.7 分钟的示范数据。

### ② 为什么以前不行？

- **数据少且不可行**：重定向出来的人体动作，机器人做不出来（不满足动力学）；
- **端到端 RL 太难**：人形 29 个关节 + 平衡，从零学不现实；
- **直接用重定向参考**：部署时拿不到"人类示范"这个参考，性能会崩。

### ③ 作者提出了什么办法？

1. **数据**：把 29 段变 7,184 段（SBTO + 对称）；
2. **架构**：扩散规划器 + RL 追踪器；
3. **后训练**：先 SD:DPO 去依赖，再 DA:PPO 提成功率。

### ④ 为什么可能更好？

- **分工合理**：规划器管"做什么动作"，追踪器管"怎么保持平衡"；
- **先验可迁移**：SD:DPO 把"详细参考"的指导蒸馏进"只看目标"的学生；
- **奖励可归因**：DA:PPO 把执行奖励分摊到去噪的每一步，解决了"奖励只在最后给"的信用分配问题。

### ⑤ 最后取得什么结果？

pick-carry-place **98.8%**、kick 68.1%、push/pull 52.7%；泛化到 5 m 外、四个朝向仍有 88%；G1 真机零微调成功。

### ⑥ 最重要的结论是什么？

> **"强先验预训练 + 蒸馏去除依赖" 比 "一开始就不给先验" 好得多**（74.1% vs 100% 存活）。
> 这给所有"部署时拿不到训练时信息"的场景提供了一个范式：**先带着拐杖学，再学会不用拐杖。**

## 五、关键结论与数字（全部可追溯）

### 5.1 数据增广的作用（表 I，pick-carry-place）

| 预训练语料 | 参考来源 | 存活 % | 任务成功 % | MPKPE cm ↓ |
|---|---|---|---|---|
| SBTO + 对称 | 预训练规划器 | 96.5 ± 1.5 | 51.9 ± 4.5 | 8.5 ± 0.6 |
| | + DPPO-style (T=0) | 99.1 ± 0.1 | 94.0 ± 3.5 | 4.9 ± 0.3 |
| | **+ DA:PPO** | **100.0 ± 0.0** | **96.4 ± 3.4** | **4.3 ± 0.2** |
| SBTO | 预训练 | 92.3 ± 4.0 | 47.5 ± 6.3 | 8.6 ± 0.7 |
| | + DA:PPO | 100.0 ± 0.0 | 92.5 ± 4.7 | 4.1 ± 0.1 |
| 单份 + 对称 | 预训练 | 90.7 ± 4.9 | 49.1 ± 7.8 | 8.8 ± 0.8 |
| | + DA:PPO | 100.0 ± 0.0 | 89.4 ± 5.0 | 6.1 ± 0.3 |
| 单份 | 预训练 | 90.0 ± 5.5 | 57.1 ± 7.8 | 9.0 ± 1.3 |
| | + DA:PPO | 93.3 ± 4.4 | 72.3 ± 7.5 | 8.8 ± 1.3 |
| 无规划器 | IK 参考 | 93.5 ± 4.5 | 53.0 ± 8.3 | 8.2 ± 0.7 |
| 无规划器 | SBTO 解 | 100.0 ± 0.0 | 61.6 ± 8.0 | 6.6 ± 0.4 |

**读法（三个重要观察）**：
1. **只有"两种增广都用"才能到 96.4%**；只增广一种，DA:PPO 后只有 89.4–92.5%；
2. **"无规划器 + SBTO 解"能到 61.6%**——说明**追踪器本身很强**，规划器的价值在于"把成功率从 61.6 推到 96.4"；
3. **DPPO-style（T=0）也能到 94.0%**，但 DA:PPO 更高（96.4%）且存活 100%。

### 5.2 任务先验的重要性（图 4，预训练模型的闭环存活率）

| 条件 | 存活 % |
|---|---|
| 机器人 + 物体运动（全参考） | **96.3** |
| 人类运动（未重定向） | 87.0 |
| 根 + 末端执行器 | 89.1 |
| 末端执行器 | 85.4 |
| 稀疏末端（每 5 帧） | 84.3 |
| 仅物体 | 70.6 |
| 无 | **45.3** |

**读法**：**先验越强，存活越高**；完全不接地只有 45.3%。这条曲线是 SD:DPO 存在的理由——**预训练需要强先验，但部署拿不到，所以要蒸馏**。

### 5.3 SO(3) vs 欧氏旋转扩散（表 II）

| 旋转扩散 | 存活 % | 任务成功 % | Obj. ori. ° ↓ |
|---|---|---|---|
| **SO(3)** | **96.5 ± 1.5** | **51.9 ± 4.5** | **14.0 ± 1.3** |
| 欧氏（6D 当欧氏） | 85.9 ± 5.0 | 46.4 ± 5.7 | 19.6 ± 2.5 |

**读法**：只在流形上做扩散，存活率就 +10.6 点。**"尊重几何"是有回报的。**

### 5.4 动作级 vs 运动级扩散（表 III）

| 模型 | 存活 % | 任务成功 % |
|---|---|---|
| **状态扩散 + 追踪器（本文）** | **96.5 ± 1.5** | **51.9 ± 4.5** |
| 动作扩散（PDP 风格） | 87.5 ± 3.7 | 45.3 ± 4.8 |
| 状态-动作扩散（BeyondMimic 风格） | 58.2 ± 7.1 | 8.2 ± 3.6 |

**读法**：**分层（规划运动 + RL 追踪）明显优于直接出动作**。作者的解释：动作级模型受限于数据覆盖，而追踪器可以在仿真里用 RL 学到"抗扰动"。

### 5.5 SD:DPO 的效果（表 V）

| 任务 | 生成器 | 存活 % | 成功 % |
|---|---|---|---|
| **Pick-place** | Self-Teacher（预训练） | 96.5 ± 1.5 | 51.9 ± 4.5 |
| | Student（预训练） | 57.7 ± 9.2 | 45.4 ± 9.0 |
| | Student + DA:PPO | 92.1 ± 4.8 | 92.1 ± 4.8 |
| | Student + SD:DPO | 100.0 ± 0.0 | 55.1 ± 6.0 |
| | **Student + SD:DPO + DA:PPO** | **99.5 ± 0.5** | **98.8 ± 1.2** |
| **Kick** | Self-Teacher | 99.9 ± 0.1 | 34.4 ± 7.2 |
| | Student | 100.0 ± 0.0 | 1.2 ± 0.7 |
| | Student + SD:DPO | 100.0 ± 0.0 | 31.9 ± 7.1 |
| | **+ DA:PPO** | **100.0 ± 0.0** | **68.1 ± 8.3** |
| **Push/Pull** | Self-Teacher | 100.0 ± 0.0 | 23.3 ± 4.9 |
| | Student | 98.7 ± 1.3 | 12.3 ± 3.9 |
| | Student + SD:DPO | 100.0 ± 0.0 | 21.7 ± 4.8 |
| | **+ DA:PPO** | **100.0 ± 0.0** | **52.7 ± 6.5** |

**读法（这是全文最重要的一张表）**：
- **Without SD:DPO**：Student + DA:PPO 能到 92.1%（说明 DA:PPO 自己也能部分补上）；
- **With SD:DPO**：98.8%（+6.7 点）——**两步互补，不是替代**；
- **Kick 上最戏剧性**：Student 单独只有 1.2%（完全没有参考就不会踢），SD:DPO 回到 31.9%，再 DA:PPO 到 68.1%；
- **No-prior 对照**：一开始就不给先验，最好也只有 67.0%——**证明"先给强先验再蒸馏"优于"一开始就不给"**。

### 5.6 奖励设计（表 IV）

| 指标 | 预训练 | +DA:PPO（$r_{kin}$） | +DA:PPO（$r_{goal}$） |
|---|---|---|---|
| 存活 % | 96.5 | **100.0** | **100.0** |
| 任务成功 % | 51.9 | **96.4** | 92.9 |

**读法**：$r_{kin}$（贴近参考）在成功率与所有跟踪指标上都优于 $r_{goal}$（只看目标）。作者最终用 $r_{kin}$。

### 5.7 泛化与部署（§V-G、§I）

- **极坐标网格**：半径 0.5–5 m、4 个朝向；训练集最远目标只有 **1.9 m**；结果 **~100% 存活、88% 成功率**；
- **真机**：Unitree G1，**零真机微调**，重复成功执行；
- **规划器推理频率**：硬件上 **12.5 Hz**。

## 六、局限性

### 6.1 作者提到的

1. **数据仍然很少**（29 段、2.7 分钟），结论依赖"重定向 + 物理可行化"这条流水线。
2. **奖励设计需要调**（$r_{kin}$ vs $r_{goal}$ 有取舍）。
3. 真机只演示了 pick-carry-place 一类任务（kick/push-pull 主要在仿真）。

### 6.2 我识别出的

| # | 局限 | 依据 | 影响 |
|---|---|---|---|
| 1 | **规划器只有 12.5 Hz** | §V-D | 对快速动态任务（接球）可能不够；占空比未知（m 未给具体值） |
| 2 | **真机样本量未报告** | §I、图 1 | 无法判断"重复成功"的统计意义 |
| 3 | **依赖 IK 重定向参考做训练** | §IV-B | 换任务需要重新重定向，扩展成本高 |
| 4 | **只有一台机器人（G1）** | 全文 | 跨形态迁移未验证 |
| 5 | **"任务成功"的定义是 15 cm / 30°** | §V | 对精细操作可能太宽松 |
| 6 | **训练用 2048 个并行环境** | 表 I 题注 | 算力门槛未明说 |
| 7 | **未开源** | 全文 | 复现门槛高 |

## 七、阅读建议

### 7.1 最值得精读的三节

1. **§IV-C + 式 (16)(17)**——SD:DPO 的"同噪声、双条件、匹配预测"设计，是全文最干净的想法。
2. **§III-C + 式 (5)–(8)**——把去噪步当决策的 DA-MDP，是理解"如何用 RL 训扩散规划器"的最佳入口。
3. **§V-G + 图 5**——5 m 外、4 个朝向仍有 88%，这是"真泛化"的证据。

### 7.2 最关键的两张表

- **表 V**：SD:DPO 与 DA:PPO 的互补性（92.1% vs 98.8%）。
- **表 I**：数据增广的组合效应（只有"都用"才到 96.4%）。

### 7.3 最重要的公式

- 规划器生成：$\hat s^{D,\tau}_\tau\sim G_\phi(\cdot\mid c_\tau,s^{IK}_\tau)$；
- 追踪器残差：$q^{PD}_j=q^{ref}_j+a_j$；
- SD:DPO 蒸馏：$\mathcal{L}_{distill}=\mathrm{MSE}(\hat v^{k,\emptyset}_\phi,\mathrm{sg}(\hat v^{k,IK}_{\bar\phi}))+\mathrm{MSE}(\hat\epsilon^{R,k,\emptyset}_\phi,\mathrm{sg}(\hat\epsilon^{R,k,IK}_{\bar\phi}))$；
- DA:PPO 损失（式 8）。

### 7.4 必须理解的五个术语

`planner-tracker`、`SBTO`、`SD:DPO`、`DA:PPO`、`DA-MDP`。

### 7.5 三个自测问题

1. 为什么"预训练时给了 50% 空 token，部署时不给参考还是会掉"？
2. SD:DPO 里为什么要"从 buffer 里取学生自己的计划"再匹配老师，而不是用数据集里的动作？
3. 为什么 DA:PPO 的奖励只给最后一步（$k=1$），却能让前面所有去噪步都得到更新？

### 7.7 是否建议复现

**不建议完整复现**（人形 + mjlab 仿真 + 2048 并行环境 + 私有重定向数据）。
**建议复现"SD:DPO 的思想"**：在任意"有特权信息"的设置里（如仿真里有真值、部署只有观测），验证"先带着特权学，再蒸馏掉"。见 [[Paper_010_DiPLO/05_科研启发与复现建议]]。

## 八、我的一句话评价

> **DiPLO 最漂亮的地方不是"用扩散做规划"，而是它承认了一个现实：**训练时你能拿到的东西，部署时拿不到**。**
> 于是它把"运动学参考"当成一种特权信息，先靠它学会，再通过自蒸馏摆脱它。这个"先带拐杖、再扔拐杖"的范式，比任何架构创新都更可迁移——**因为在机器人学习里，训练/部署的信息不对称是常态。**
