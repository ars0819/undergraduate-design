## 二、六个概念的五层解释

### 2.1 策略引导（Policy Steering）

1. **一句话**：不改模型，改"它怎么生成"。
2. **类比**：不换司机，只在方向盘上加一个助力——司机还是那个人，但车会往你希望的方向偏一点。
3. **机器人例子**：冻结的 VLA 还是自己生成动作，但每一步的速度被"往目标方向"调一下。
4. **技术原理**：在生成过程（采样/积分）中注入外部信号，修改中间状态或更新量。
5. **与本文关系**：本文把"空间线索"作为引导信号，注入了**速度场**。

### 2.2 空间线索（热图）

1. **一句话**：一张图上标出"目标大概在这里"的概率分布。
2. **类比**：地图上用一圈红晕标出"宝藏在这一带"，而不是画一个精确的方框。
3. **机器人例子**：分割出"写着 Joseph 的袋子"，算质心，在质心处放一个二维高斯。
4. **技术原理**：$h(x,y)=\exp(-\|(x,y)-c\|^2/2\sigma^2)$，$c$ 是质心。
5. **与本文关系**：热图**不画进图像**，而是单独作为一路条件——这是它与 visual prompt 的根本区别。

### 2.3 对角仿射变换

1. **一句话**：每个动作维度单独缩放加平移。
2. **类比**：调音台上每个音轨有自己的音量旋钮（缩放）和偏移旋钮（平移）。
3. **机器人例子**：$x$ 方向的速度乘 1.2、加 +0.03；$y$ 方向乘 0.9、加 −0.01；旋转维不变。
4. **技术原理**：$\tilde v=v\odot(1+\gamma)+\beta$，$\gamma,\beta\in\mathbb{R}^{d_a}$ 广播到全部 $H$ 个时间位置。
5. **与本文关系**：**"对角"是关键约束**——它保证了调制是逐维的、不会把动作维度混在一起，从而最大限度保留预训练策略的结构。

### 2.4 捷径学习（本文的核心对抗目标）

1. **一句话**：模型找到了"不用看题目也能答对"的办法。
2. **类比**：考试时发现"选 C 的都对"，于是不看题就选 C。
3. **机器人例子**：训练时热图总在目标物体上，适配器发现"只要看画面里最像袋子的东西"就够了，根本不用看热图——于是换个新物体就崩。
4. **技术原理**：训练分布中辅助信号与目标强相关，模型倾向于用更容易的特征（外观）替代更难的特征（位置）。
5. **与本文关系**：两个对比损失就是为了打断这条捷径。

### 2.5 为什么"每步调制"比"一次修正"好

1. **一句话**：每步都纠偏，比最后再改更稳。
2. **类比**：开车时每 100 米微调方向，比开到底再打方向盘更安全。
3. **机器人例子**：积分 10 步，每步都根据当前状态重新算 $\gamma,\beta$。
4. **技术原理**：流匹配的积分是迭代的；在每步修改速度场，等价于在"生成轨迹"上逐步施加引导。
5. **与本文关系**：作者明确说"因为每步重算，冻结策略会在被引导的状态上重新评估"（§3.2）。

### 2.6 冻结 + 小适配器 vs 微调

1. **一句话**：不动大模型，只加一个小外挂。
2. **类比**：不重新装修房子，只加一个智能开关。
3. **机器人例子**：0.02% 参数的适配器 vs 全模型 LoRA。
4. **技术原理**：冻结主干 → 保留预训练分布；小适配器 → 数据需求低、不易过拟合。
5. **与本文关系**：作者报告 LoRA 在 80 条示范下会过拟合（§3.4），这是"冻结"的直接理由。

## 三、公式逐个讲

### 公式 1：速度场调制（★核心）

$$
\tilde v^\tau_t = v^\tau_t \odot (1+\gamma^\tau_t) + \beta^\tau_t
$$

**性质**：🟢 **原文公式 (1)**（§3.2）。

| 符号 | 含义 |
|---|---|
| $v^\tau_t$ | 冻结 VLA 在积分时刻 $\tau$ 预测的速度（形状 $H\times d_a$） |
| $\gamma^\tau_t$ | 缩放项（$d_a$ 维，广播到 $H$） |
| $\beta^\tau_t$ | 偏移项（$d_a$ 维，广播到 $H$） |
| $\tilde v^\tau_t$ | 调制后的速度 |
| $\odot$ | 逐元素乘 |

**直观**：把策略的"速度"按维度缩放，再整体平移一点。
**为什么这样设计**：
- **乘性项 $\gamma$**：重新加权各维速度（"多往这个方向走一点"）；
- **加性项 $\beta$**：给一个恒定的方向偏移（"整体往那边挪"）；
- **对角**：不混合动作维度，最大限度保留原策略结构；
- **每步重算**：让轨迹逐步被引向目标，而不是一次性改终点。
**数字例子**（教学示例）：某维速度 $v=0.4$，$\gamma=0.5$、$\beta=0.1$ → $\tilde v=0.4\times1.5+0.1=0.7$。
**在流程中的位置**：图 2 的 M1。
**与其他公式的关系**：$\gamma,\beta$ 由公式 2/3 训练的适配器产生；$\mathcal{L}_{reg}$（公式 4）约束它们的大小。

### 公式 2：空间对比损失

$$
\mathcal{L}^i_{sp} = -\log\frac{\exp(z^i_a\cdot z^i_c/\tau)}{\exp(z^i_a\cdot z^i_c/\tau)+\sum_{k=1}^{K}\exp(z^i_a\cdot z^-_{c,k}/\tau)}
$$

**性质**：🟢 **原文公式 (2)**（§3.3）。

| 符号 | 含义 |
|---|---|
| $z^i_a$ | 动作表示（由动作专家特征 + 线索编码投影得到） |
| $z^i_c$ | 正样本线索表示（真实热图） |
| $z^-_{c,k}$ | 负样本线索表示（热图峰值平移后的 $K$ 个版本） |
| $\tau$ | 温度 |

> 原文公式还包含一个对 batch 内其他样本的求和项（标准 InfoNCE 形式），这里为便于理解只保留空间负样本部分；**完整形式见原文式 (2)**。

**直观**：动作表示应该和"正确位置的线索"更相似，和"平移后位置的线索"更不相似。
**为什么这样设计**：负样本**只改位置、不改场景**，逼编码器学位置。
**数字例子**（教学示例）：若 $z_a\cdot z_c=0.9$、与 3 个负样本的相似度为 0.2/0.1/0.3，温度 0.1：
分子 $\exp(9)$，分母 $\exp(9)+\exp(2)+\exp(1)+\exp(3)$ → 损失很小（≈0.01）。
若把热图平移后相似度反而更高，损失就会很大。
**在流程中的位置**：图 3 的 $\mathcal{L}_{sp}$。

---

### 公式 3：残差对比损失

$$
\mathcal{L}^i_{res} = -\log\frac{\exp(z^i_a\cdot z^i_{res}/\tau)}{\sum_{j=1}^{B}\exp(z^i_a\cdot z^j_{res}/\tau)}
$$

**性质**：🟢 **原文公式 (3)**（§3.3）。

| 符号 | 含义 |
|---|---|
| $z_{res}=P_\delta(E(h_t)-E(\mathbf{0}))$ | 残差线索表示（"线索增量"） |
| $B$ | batch 大小 |

**直观**：动作表示应该对齐"线索带来的那部分信息"，而不是整张热图（整张热图里混着场景信息）。
**为什么**：防止适配器从动作特征或场景外观里抄近路。
**数字例子**：无（这是相对相似度，不便于单点举例）。
**在流程中的位置**：图 3 的 $\mathcal{L}_{res}$。

---

### 公式 4：幅度正则

$$
\mathcal{L}_{reg} = \|\gamma^\tau_t\|_2^2 + \|\beta^\tau_t\|_2^2
$$

**性质**：🟢 **原文公式 (4)**（§3.3）。

**直观**：别把动作推得太狠。
**为什么**：过度调制会破坏预训练策略的动作分布，导致动作不自然甚至失败。
**数字例子**：$\gamma=0.5,\beta=0.1$ → $0.25+0.01=0.26$；若 $\gamma=2.0$ → $4.0$，惩罚大得多。
**在流程中的位置**：图 3 的 $\mathcal{L}_{reg}$。

---

### 公式 5：总损失

$$
\mathcal{L}=\mathcal{L}_{flow}+\lambda_{sp}\mathcal{L}_{sp}+\lambda_{res}\mathcal{L}_{res}+\lambda_{reg}\mathcal{L}_{reg}
$$

**性质**：🟢 **原文公式 (5)**（§3.3）。**注意：原文未给三个 $\lambda$ 的具体数值。**

| 项 | 作用 |
|---|---|
| $\mathcal{L}_{flow}$ | 保证调制后的动作仍然符合示范分布 |
| $\mathcal{L}_{sp}$ | 让线索表示对位置敏感 |
| $\mathcal{L}_{res}$ | 让线索表示"隔离"出增量信息 |
| $\mathcal{L}_{reg}$ | 控制调制幅度 |

**消融效果**（图 5，移动 Setting III）：
- 只有 $\mathcal{L}_{flow}$：16.7%
- + $\mathcal{L}_{sp}$：33.3%
- + $\mathcal{L}_{res}$：41.7%

### 公式 6：积分更新（沿用流匹配，非本文新公式）

$$
A^{\tau+\Delta\tau}_t = A^\tau_t + \Delta\tau\,\tilde v^\tau_t,\qquad \Delta\tau=-\frac{1}{N}
$$

**性质**：🟡 原文描述（"integration proceeds from τ=1 to τ=0 with signed step Δτ = −1/N"），形式为流匹配标准写法。

**注意符号方向**：本文从 $\tau=1$（噪声）积到 $\tau=0$（动作），所以步长是负的。这与 π0 的"从 0 到 1"写法相反，**阅读时别搞混**。

**在流程中的位置**：图 2 的 U1。

## 四、符号总表

| 符号 | 含义 |
|---|---|
| $\tau$ | 积分时刻（1 = 噪声，0 = 动作） |
| $\Delta\tau=-1/N$ | 积分步长 |
| $v^\tau_t$ | 冻结 VLA 的速度场 |
| $\gamma^\tau_t,\beta^\tau_t$ | 调制参数（逐维） |
| $\tilde v^\tau_t$ | 调制后速度 |
| $h_t$ | 高斯热图 |
| $E(\cdot)$ | cue encoder |
| $P_c,P_a,P_\delta$ | 三个投影头 |
| $z_c,z_a,z_{res}$ | 线索 / 动作 / 残差表示 |
| $\tau$（对比损失里） | 温度（**与积分时刻同名，易混**） |

> [!warning] 一个记号冲突
> 原文里 $\tau$ 既是**积分时刻**又是**对比损失的温度**。这是论文的记号不严谨之处，读公式时要靠上下文区分。

## 五、最容易混淆的三组概念

| 容易混淆 | 区别 | 记法 |
|---|---|---|
| **visual prompt vs spatial cue** | 前者画进图、隐式；后者单独一路、显式 | "画进去" vs "喂进去" |
| **缩放 γ vs 偏移 β** | 前者改变"往这方向走多少"，后者给恒定偏移 | 调增益 vs 加偏置 |
| **两个 τ** | 积分时刻 vs 对比温度 | 看上下文 |
