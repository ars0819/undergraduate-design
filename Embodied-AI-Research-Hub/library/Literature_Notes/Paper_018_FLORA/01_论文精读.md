# P018 · Beyond Pixels（FLORA）论文精读

> [!abstract] 一句话先给你
> **视觉奖励模型在"换个位置、换个视角、换个物体"之后就不灵了，因为它们学的是像素分布。** FLORA 换了个思路：不学"看起来像不像成功"，而学**行为不变量**——把 5 条示范提炼成一段**符号程序**（用 LLM 写、用贝叶斯优化调参），再套上**势函数奖励塑形（PBRS）**保证"塑形不改变最优策略"。结果在 8 个 Meta-World 任务 + 3 个 Franka 真机任务上，**进度对齐 0.97（次优 0.89）**，而且在位置/视角/物体三种 OOD 下**同一个奖励模型零样本迁移**。

## 二、三种长度的摘要

### 2.1 30 秒摘要（约 160 字）

奖励函数是 RL 的瓶颈。用视觉模型学奖励的问题在于：**它记住的是像素，不是任务逻辑**——桌子挪一下、相机换个角度，分数就乱了。FLORA 的做法是：用 DINOv2 + 3D 点跟踪把画面转成"物体中心的运动流"，让 LLM 据此写出一段**符号势函数程序**，参数用贝叶斯优化调，再套上 PBRS 保证不改变最优策略。只用 5 条示范，就能在 OOD 场景零样本复用同一个奖励。

### 2.2 3 分钟摘要（约 500 字）

**问题。** 开放世界操作里，同一个任务会有无数变体（不同物体实例、位置、相机视角）。现有奖励模型有三类，各有短板：
- **VLM 直接打分**：语义强，但分数在时间上不连续、数值不校准；
- **大规模数据训的奖励模型**（LIV、VLC、ReWiND、SARM）：精度更高，但**视觉分布偏移下会退化**（原文直接引表 I 为证）；
- **程序化奖励**（Eureka、Text2Reward 用 LLM 生成代码）：可解释、能表达物理约束，但**依赖特权状态**（如真值 6D 位姿），且需要大量仿真交互。

**洞察。** 作者提出一个关键转向：**不要拟合视觉特征，要发现"行为不变量"（behavioral invariants）**——即那些在不同视觉实例化下保持不变的任务级属性（如"夹爪接近了把手"、"物体被抬起来了"）。

**方法（三个组件）。**
1. **Flow-Generator（把像素变成运动流）**：先用 Grounding DINO 在参考图上标出 RoI（夹爪/被操作物/目标），之后每个 episode 用 **DINOv2 稠密对应**重新定位 RoI，再用 **3D 点跟踪器（TAPIR3D）**在 episode 内跟踪，最后把所有轨迹点表达在**规范化的物体中心坐标系**里 → 得到运动流 $o_t$。这一步是"空间不变性"的来源。
2. **Symbolic Potential Function（符号势函数）**：$\phi(o_t, o_0;\theta)\to(p_t,\hat\mu_t)$，输出标量进度与辅助阶段预测。它被拆成**符号结构** $\phi\in\Phi$（由 LLM 写的程序）与**数值参数** $\theta\in\Theta$（阈值、权重、增益）。
3. **PBRS-MS（带里程碑的势函数塑形）**：直接套 PBRS 在操作任务里会"势能坍塌"——比如"拿起来又掉了"的轨迹，其前缀塑形和"从没拿起过"一样，导致时序信用分配失效。作者加了**里程碑索引** $m_t=\max(m_{t-1},\max\{k\mid\phi(s_t)\ge\kappa_k\phi_{\max}\})$，把"已经到达的最高进度"记下来，提供全局信号。

**怎么学（全离线、双层优化）。**
- **内层（数值）**：对每个候选符号结构 $\phi_k$，用**贝叶斯优化**（UCB 采集函数）调 $\theta$；
- **外层（符号）**：LLM 当"符号优化器"，每批把 top-$m$ 候选（按训练与验证分数）连同分数与势函数轨迹图作为反思材料，让 LLM 诊断失败原因并改写程序。

**评价指标（三个，都很讲究）**：
- **进度对齐** $\rho$：奖励与归一化时间 $t/T$ 的 **Spearman** 相关（式 6）——用秩相关而非 Pearson，因为只要求"单调"不要求"线性"；
- **奖励排序**：同一任务不同轨迹的排序正确性；
- **奖励差**：好轨迹与坏轨迹的分数差；
- **PBRS 正性** $C_{pbrs}$（式 7）：塑形信号非负的比例——这是"塑形是否真的在引导"的直接指标。

**结果（表 I）**：
- **训练任务**：进度对齐 **0.97**（LIV −0.13、LIV-FT 0.78、VIP-FT+PBRS 0.80、VLC 0.86、ReWiND 0.89）；排序 **0.80**（次优 0.53）；奖励差 **0.80**（次优 0.27）；
- **Position OOD**：0.85 / 0.57 / 0.46；
- **Viewpoint OOD**：0.88 / 0.67 / 0.46；
- **Object OOD**：0.81 / 0.53 / 0.32；
- **关键对照**：LIV **不做微调时是负相关**（−0.13），说明"零样本视觉奖励"在操作任务上基本不可用；而 FLORA 是唯一在**三种 OOD 上都不掉太多**的方法。

### 2.3 一句话核心创新

> **用"物体中心运动流 + LLM 生成的符号势函数 + PBRS 里程碑"把奖励从"像素匹配"变成"行为不变量"，从而用 5 条示范得到可零样本迁移的稠密奖励。**

## 三、用大白话回答六个问题

### ① 想解决什么问题？

怎么只用**几条示范**，就得到一个**在换位置、换视角、换物体后仍然有效**的奖励函数。

### ② 为什么以前不行？

| 路线 | 问题 |
|---|---|
| VLM 直接打分 | 分数不连续、不校准；换个视角就变 |
| 大规模奖励模型（LIV/ReWiND） | 学的是视觉分布，OOD 退化 |
| LLM 生成代码奖励（Eureka 等） | 依赖真值位姿等特权信息；要大量仿真交互 |
| 传统 IRL / 偏好学习 | 要预定义特征或大量人工反馈 |

### ③ 作者提出了什么办法？

把"像素"换成"运动流"，把"神经网络"换成"符号程序"，把"直接塑形"换成"PBRS + 里程碑"。

### ④ 为什么可能更好？

- **运动流**天然对位置/视角不变（因为在物体中心坐标系里表达）；
- **符号程序**能表达逻辑（先抓住、再抬起、再移动），而不是拟合外观；
- **PBRS** 在理论上保证"不改变最优策略"——这是作者反复强调的 `optimal policy invariance`；
- **里程碑**解决 PBRS 在长时任务里的"势能坍塌"。

### ⑤ 最后取得什么结果？

训练任务进度对齐 0.97、OOD 0.81–0.88；同一个奖励模型不重训就能指导真机 RL。
（真机具体数字我**未逐页核实**。）

### ⑥ 最重要的结论是什么？

> **奖励的"不变性"不来自更大的视觉模型，而来自更好的表示选择**——把奖励定义在"物体相对运动"上，而不是"像素"上。

**读法（四点）**：
1. **LIV 零样本是负相关**（−0.13）——说明"预训练视觉奖励直接拿来用"在操作任务上不成立；
2. **LIV 微调后（0.78）就能追上多数基线**——这提示"微调"本身贡献很大，fair comparison 要看 LIV-FT；
3. **FLORA 的优势在"排序"和"奖励差"上最大**（0.80 vs 0.53 / 0.27）——说明它不只是"平均分数对"，而是"**能区分好坏轨迹**"，这才是 RL 真正需要的；
4. **OOD 下所有方法都掉，但 FLORA 掉得最少**（视角 OOD 只从 0.97 掉到 0.88）。

### 5.2 评价指标的三个定义（§V）

- **进度对齐**（式 6）：$C_{prog}(\phi)=\text{Corr}(\phi(o_t), t/T)$，用 **Spearman** 而非 Pearson——"单调即可，不要求线性"；
- **PBRS 正性**（式 7）：$C_{pbrs}(\phi)=\frac{1}{T-1}\sum_t \mathbf{1}\{\gamma\phi(o_{t+1})-\phi(o_t)\ge0\}$——衡量"塑形信号有多少是非负的"，即"奖励是否总在推着往前走"。

## 八、我的一句话评价

> **这篇的核心不是"用 LLM 写奖励"（Eureka 已经做过），而是**"把奖励定义在什么表示上"**：从像素 → 物体中心运动流。**
> 表 I 里最有信息量的一行是 **LIV 零样本 −0.13**——它说明"看起来像成功"和"真的在成功"是两件不同的事。而 FLORA 的 0.97 说明：**只要表示选对了，5 条示范就够。**
