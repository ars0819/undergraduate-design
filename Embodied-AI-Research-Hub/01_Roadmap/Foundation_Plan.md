## 1. 原则

1. **先诊断，后学习**：已会的跳过，不按目录从第一页开始。
2. **一个时间只开一门主课**：当前主课是吴恩达 ML；数学用短复习插入。
3. **代码优先**：每个模块必须产出一个可运行的小东西，否则不算学过。
4. **允许定向补课**：围绕实际报错/论文公式补，不为“完整性”囤课。
5. **不把课程完成当实验门槛**：没刷完 CS231n/CS285 也可以先读 VLA 推理代码。

## 3. 四个诊断（先做，不急着上课）

### D-Py：独立小工具

写一个纯 Python 脚本，读入一组延迟数（可先硬编码/命令行），输出样本数、均值、p50、p95；空输入、非数字、单个值要有明确行为；写 3 个测试。  
**通过**：不查完整答案，60–90 分钟完成；能解释每个函数；测试可重跑。

### D-NumPy：shape 与统计

用 NumPy 重做上面的统计；构造 `(N,)`、`(N,1)`、`(N,D)` 三种数组；说明 `*`、`@`、广播的结果。  
**通过**：能先预测 shape 再运行；能解释 `(N,)` 与 `(N,1)` 的差异；空数组行为明确。

### D-Math：链式与 Newton

3 道复合函数求导；1 道线性近似；1 道“Newton 求根与梯度下降的区别”。  
**通过**：能写内外层；能说明梯度方向；能写出一次 Newton 更新并说明何时不适用。

### D-ML：损失与更新

3 个样本，手算平方误差、平均损失、w/b 梯度与一次同时更新；解释为什么要用旧参数。  
**通过**：数字正确；能说清 loss 与 cost 的区别；能指出学习率过大/过小的现象。

## 4. 推荐顺序（可跳）

```text
D-Py → D-NumPy → D-Math（链式/近似） → D-ML（损失/更新）
   → PyTorch 最小训练链 → 反向传播/诊断
   → 机器人学习基础（BC/MDP） → 实验规范
```

- 如果 D-Py 通过：跳过 Python 入门课，直接写小工具。
- 如果 D-NumPy 通过：只补广播/`axis` 的薄弱点。
- 如果 D-Math 通过：不重看 18.01 全课，只补 Newton/积分等实际用到的。
- 如果 D-ML 通过：直接进入 PyTorch；不重刷吴恩达已会部分。
- 如果任何一项不通过：只补该项 2–3 个学习日，不扩大成“重新开始”。

## 5. 时间预算

| 场景 | 基础线/周 | 说明 |
|---|---:|---|
| 实验推进期 | 4–6 h | 只补当前卡点；代码/实验优先 |
| 等待资源/环境期 | 8–12 h | 保持 Python/NumPy/ML 连续性 |
| 课程繁忙/考试周 | 2–4 h | 只做一个最小练习，不补课债 |
| 完整空闲周 | 12–15 h | 不超过；留时间给复盘和休息 |

不设“每天必须 3 小时”。旧 V3 的 18 h/周是历史预算，不是当前合同。

## 6. 课程取舍

- 吴恩达 ML：当前主课，按主题跳看；不追求 P 数。
- MIT 18.01：只复习当前用到的导数/链式/近似/极值；Newton 单独补。
- 18.02/18.06/概率：遇到多变量梯度、最小二乘、评估不确定性再补。
- CS231n/CS285/DLS：作为按需资源，不作为当前主线；需要时只取相关章节。
- PyTorch：官方教程优先于旧视频；安装版本以实际环境为准。

资源入口：[`Courses.md`](../06_Resources/Courses.md)。

## 7. 退出/降级规则

- 连续 2 周没有代码产出：把基础线降为每周 2 次，先恢复“能运行”的信心。
- 某个模块连续 3 天卡住：缩小练习，回到一个可手算的例子；不换更多课程。
- 实验资源到位：基础线自动降为 4–6 h/周，优先毕设。
- 身体/课程压力大：允许暂停新内容，只保留复习；不把暂停写成“已掌握”。
