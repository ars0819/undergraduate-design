# Literature

论文条目、优先级、阅读状态统一放在 [`06_Resources/Papers_Index.md`](../../06_Resources/Papers_Index.md)，避免同一篇论文两套状态。  
实验室/团队观察放在 [`Researchers_Labs/Reading_Watchlist.md`](../Researchers_Labs/Reading_Watchlist.md)。

## 规则

- 先有研究问题，再收论文；每篇写“与哪个 RQ 有关”。
- 未读全文：只写“待读/摘要级”，不写方法细节。
- 不按团队名气自动进必读。
- Zotero 继续管理条目/PDF/引用；本库不复制 PDF，不改 Zotero 数据库。
- 读完后用 [`Paper_Note.md`](../../07_Templates/Paper_Note.md) 建独立笔记。
