# Advisor Feedback

> **重要**：以下是用户对 2026-11-06 导师交流的**转述/摘要**，不是逐字会议纪要，也不是导师对题目/任务书的批准。  
> 正式材料以导师/学院书面确认件为准；不要把本页当“已批准”。

## 1. 已明确的方向（用户转述）

1. 不要被具身智能的热门研究方向牵着走。
2. 不以 Agent、Robot-Use Agent、世界模型或机器人大脑作为本科主研究目标。
3. 本科阶段可以先复现已有研究工作。
4. 本科与博士主要关注轻量化、高效推理与实际部署。
5. 重点关注机器人学习基础、Sergey Levine、许华哲等团队，以及 MIT 韩松实验室高效 AI 计算工作。
6. 近期本科毕设考虑开源 VLA 推理复现与部署评测。

一句话：**具身模型轻量化、高效推理、部署；本科允许已有工作复现。**

## 2. 对计划的直接影响

| 方向 | 处理 |
|---|---|
| 世界模型/多智能体/大规模 RL | 转扩展阅读/博士衔接，不占本科主线 |
| Agent/机器人大脑 | 不当前置，不做主线 |
| VLA 推理复现 | 提升为本科主线 |
| 高效推理/部署 | 从旧路线后段提升为持续主线 |
| 复现 | 允许且优先；不要求原创算法 |
| OpenFleX | 未来接口对象；当前可用性未验证 |

## 3. 近期候选（未批准）

- 首选：SmolVLA + LIBERO。
- 备用：OpenVLA-OFT + LIBERO。
- 所有运行状态以真实日志为准；当前均为“计划中/未开始”。

## 4. 下次见导师要问

1. 题目是否采用“轻量化与高效推理部署”？若只做 compile，题目是否收窄？
2. 一种开源 VLA 复现 + 一种优化 + 工程验证，是否满足本科工作量？
3. 纯 LIBERO 仿真 + 系统设计，是否满足学院/专业要求？是否必须机械结构/实物？
4. 是否认可 SmolVLA 首选、OFT 备用？切换条件？
5. A100 40GB 的可用时段、单次时长、存储、网络、是否独占/计费？
6. 可接受的性能损失/成功率下降是多少？是否接受“省显存但更慢”的负结果？
7. OpenFleX 何时可用？SDK/ROS、急停、自由度、相机、标定、数据责任人？
8. 权重/数据/日志的存放与备份规范？是否允许本地保存？
9. 正式任务书模板、题目类型、项目来源、跨院/校外指导审批？
10. 是否需要量化作为主线？若需要，是否接受 A100 + 真实内核路线？
