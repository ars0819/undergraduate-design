# 按技术主题分类的文献矩阵

表中价值与风险为我的学习/选题分析。具体作者结论、硬件和原文位置见卡片；不是统一硬件重测榜单。

|文献|技术主题|改变的环节/机制|本科使用价值|迁移风险|
|---|---|---|---|---|
|[Transformer](../01-基础机器学习/Transformer.md)|注意力基础|编码器/解码器堆叠、多头注意力、位置编码、前馈层、残差归一化。|今天不必完整读完，可作为ACT卡片中不懂模块的查询页。|全注意力常有二次序列成本；注意力权重不等于严格因果解释。|
|[DDPM](../01-基础机器学习/DDPM.md)|扩散生成基础|固定高斯正向过程；参数化反向均值；简化噪声预测目标。|为动作头加速、采样步数实验建立概念基础，不必先训练图像扩散模型。|多步采样慢；简化损失与完整似然目标并不完全一致；图像质量不能保证控制可行性。|
|[ACT](../02-机器人模仿学习/ACT.md)|动作分块|动作分块 + Transformer + CVAE；时间集成融合的是对同一时刻的多次预测。硬件遥操作设计也是贡献。|毕设起点：先用动作块理解时序与接口，再讨论VLA调度。OpenFleX需重新核对关节、相机、动作频率和示范格式。|固定任务分布、相机和示范质量影响大；时间集成会额外调用模型，不能天然视为加速。|
|[DiffusionPolicy](../02-机器人模仿学习/DiffusionPolicy.md)|扩散动作生成|条件去噪生成动作序列，视觉特征作条件；滚动时域执行；比较CNN与时序Transformer。|适合作为小任务基线，分析采样步数、执行时域和反馈延迟的耦合。|迭代去噪有延迟；离线动作误差不能充分预测闭环成功；多模态生成不等于任务规划。|
|[RT1](../02-机器人模仿学习/RT1.md)|多任务策略规模化|语言条件视觉编码、Token压缩与Transformer离散动作预测。|了解数据扩展路线，本科不复刻其大规模采集。|平台与任务覆盖有限，训练成本高。|
|[OXE](../02-机器人模仿学习/OXE.md)|跨具身数据|标准化数据集合与RT-X模型正迁移评估。|本科先研究接口与小样本，不下载全量跨平台数据。|负迁移与数据失衡仍可能存在；网络下载和存储成本大。|
|[DP3](../02-机器人模仿学习/DP3.md)|三维表示扩散策略|稀疏点云轻量编码器 + diffusion policy。|作为机器人感知补充，当前先确认传感器再决定实现。|点云缺失/标定/遮挡、深度噪声与预处理延迟。|
|[SmolVLA](../03-VLA基础模型/SmolVLA.md)|轻量VLA与异步|SmolVLM2特征 + 流匹配动作专家；视觉Token缩减、层截断和异步执行。|推荐作为12GB条件下优先评估的VLA候选；先离线推理，后小规模模拟，而非预训练。|新硬件仍需示范微调；原生Windows、5070驱动/算子和峰值显存未本机实测。|
|[OpenVLA](../03-VLA基础模型/OpenVLA.md)|离散动作VLA|双视觉编码器融合 + Llama2 + 动作分箱；公开训练和LoRA/量化适配流程。|理解离散动作VLA基线，量化/缓存方案应先确认目标层与计算路径。|5070 12GB不宜默认全精度放得下；量化内核兼容与闭环精度需验证。|
|[RT2](../03-VLA基础模型/RT2.md)|网络知识迁移|VLM与机器人轨迹/图文任务共同微调，动作作为Token。|历史路线阅读，帮助区分语义和控制泛化。|代码/完整权重未核实公开，昂贵模型不适合作为首个实现目标。|
|[Octo](../03-VLA基础模型/Octo.md)|模块化通用策略|模块化tokenizer、Transformer共享主干与可适配动作readout。|接口思想值得借鉴，本科不必同时维护多套训练框架。|JAX工具链与新平台接口增加学习成本；泛化依赖数据。|
|[pi0](../03-VLA基础模型/pi0.md)|流匹配动作专家|PaliGemma视觉语言主干与流匹配动作专家联合建模；跨机器人预训练和任务后训练。|读结构以理解动作头加速；12GB上整模型与多相机实测前不承诺可运行。|多步动作专家有延迟；大规模私有机器人数据限制完全复刻；新平台需动作归一化。|
|[pi05](../03-VLA基础模型/pi05.md)|异构数据泛化|异构任务共同训练、离散/连续动作表示结合、高层语义子任务和后训练。|为博士理解高低层决策；本科主线仍宜小模型上可测的延迟/误差问题。|新环境能力依赖数据覆盖；系统仍可能失误；本轮未验证5070可用配置。|
|[AWQ](../04-高效模型与推理加速/AWQ.md)|权重低比特量化|用激活统计搜索输入通道缩放；权重缩放与输入逆缩放保持浮点等价，再执行量化；TinyChat负责系统实现。|毕设可做模块敏感性与校准集研究，先小模型，不从7B全流程移植起步。|仅权重低比特；视觉/动作头覆盖、校准数据和内核支持决定VLA收益。|
|[VLASH](../04-高效模型与推理加速/VLASH.md)|未来自身状态对齐|未来自身状态滚动预测 + 状态/动作一起偏移的微调数据增强；可共享观测编码；动作重采样调节执行速度。|优先研究概念和轻量延迟注入实验；真机交付后再做车臂状态与执行队列适配。|未来外界仍未知；接触/打滑使状态外推偏差扩大；低显存微调TODO不能视为已验证。|
|[ForeAct](../04-高效模型与推理加速/ForeAct.md)|视觉前瞻规划|VLM子任务规划 + SANA风格未来图像生成 + 附加视觉条件VLA；云边闭环部署。|博士衔接可研究预测价值与调度；本科先离线评价视觉目标，不训练完整生成器。|规划幻觉、未来图像可达性、远程时延与额外算力；没有验证OpenFleX/5070整栈。|
|[RTC](../04-高效模型与推理加速/RTC.md)|推理时动作补全|冻结已承诺前缀，对剩余动作做推理时inpainting，软掩码控制跨块连续性。|无需改训练的思路值得作为异步对照；本科先做固定延迟、变化延迟与动作突变的小模拟。|推理时引导增加开销；执行承诺前缀限制即时反应；基础策略离分布仍可失败。|
|[EfficientVLA](../04-高效模型与推理加速/EfficientVLA.md)|层/Token/去噪步压缩|非连续语言层剪枝 + 任务相关/多样性视觉选择 + 迭代动作头中间量缓存。|适合作为多模块分析范例；本科只挑一项变量做受控实验。|层相似可能遗漏任务关键的小变化；组合误差叠加；免训练不代表无需校准和工程适配。|
|[VLACache](../04-高效模型与推理加速/VLACache.md)|跨帧视觉KV复用|相邻图像patch余弦相似度 + 任务相关过滤 + 逐层自适应KV复用。|很适合做静止/移动相机下缓存失效与刷新实验；需真实闭环评估才可宣称控制改进。|移动相机、光照与接触小变化可令缓存过期；视觉前端是否仍重算需查实现。|
|[OpenVLAOFT](../04-高效模型与推理加速/OpenVLAOFT.md)|连续并行动作块|并行动作解码 + chunking + 连续表示 + L1回归；更新版OFT+含FiLM增强语言联系。|动作头设计与接口评估的重要文献；12GB先读，硬件实测后再决定基线。|多个设计同时变化；真实任务仍需示范；大主干显存和推理内核门槛存在。|
|[FAST](../04-高效模型与推理加速/FAST.md)|动作频域Token压缩|DCT变到频域、量化系数、展平与BPE压缩；FAST+为跨数据动作tokenizer。|可先用本地小动作数组做无模型压缩实验，门槛低于训练VLA。|压缩可能损失接触瞬间高频细节；自回归仍需输出Token；重建好不必然控制好。|
|[SmoothQuant](../04-高效模型与推理加速/SmoothQuant.md)|W8A8量化|等价通道缩放，把激活量化难度迁到权重。|量化方向概念补充，小矩阵练习先行。|激活分布变动与内核适配影响效果。|
|[FlashAttention](../04-高效模型与推理加速/FlashAttention.md)|IO感知精确注意力|IO感知分块、在线softmax、重计算。|帮助设计公平计时与算子兼容实验。|短序列、mask、缓存路径与GPU架构可影响收益；精确指算法目标，浮点仍可能有微差。|
|[ConsistencyPolicy](../04-高效模型与推理加速/ConsistencyPolicy.md)|一致性蒸馏|从扩散教师蒸馏一致性学生，减少采样步数。|本科候选D的参考；先用小动作任务验证。|蒸馏成本与教师偏差；少步模型可丢失动作模式。|
|[TrainingTimeRTC](../04-高效模型与推理加速/TrainingTimeRTC.md)|训练时前缀条件|训练中模拟延迟并直接条件化已承诺动作前缀。|适合异步方向后续扩展，非本科第一步。|需要相应训练数据和延迟模拟；极端未见延迟泛化待核。|
|[SAC](../05-世界模型与强化学习/SAC.md)|模型无关强化学习|最大熵目标、随机actor、soft critic与经验回放；原始2018版本含单独V网络，勿混同后续常用版本。|博士决策基础；本科优先理解小环境，不与大型VLA训练同时开题。|需要奖励和交互；模拟成功不等于真机可直接探索；熵系数与奖励尺度耦合。|
|[WorldModels](../05-世界模型与强化学习/WorldModels.md)|潜空间动态模型|VAE视觉压缩V、混合密度RNN动态M、小线性控制器C；用进化策略优化控制参数。|适合建立世界模型直觉；不建议本科先预训练通用视频模型。|潜空间预测误差会累积；梦境任务被利用；不包含完整物理可达性保证。|
|[DreamerV3](../05-世界模型与强化学习/DreamerV3.md)|想象actor-critic|循环状态空间模型、潜空间想象actor-critic；symlog等稳健预测、损失平衡与归一化。|博士中可研究延迟、模型误差和决策的耦合；本科先读稳健预测而非复刻Minecraft。|世界模型偏差与想象滚动长度耦合；不直接验证新双臂接触任务；计算/交互成本仍需预算。|
|[ReviewRealWorld](../06-综述文献/ReviewRealWorld.md)|全栈部署综述|从挑战、结构、训练、数据、真实应用到实践建议建立全栈分类。|本科先用它列约束和选题问题；博士长期维护分类而非追逐单一排行榜。|范围广而细节密度有限；综述时效与条目更新不等于最新状态已核实。|
|[SurveyEmbodied](../06-综述文献/SurveyEmbodied.md)|VLA分类综述|按组件、低层控制策略与高层任务规划分类，汇总资源和挑战。|作为概念补查索引。|版本更新和分类边界可能改变，不能代替方法复核。|
|[SurveyLargeVLM](../06-综述文献/SurveyLargeVLM.md)|整体/分层架构综述|整体式与分层式分类，讨论RL、免训练优化、视频与世界模型。|帮助本科选结构范围，避免把所有方向同时做。|分类不能覆盖所有混合架构；更新范围受版本限制。|
|[SurveyWAM](../06-综述文献/SurveyWAM.md)|世界动作耦合综述|统一WAM范围与分类，讨论表示、动态、动作接口和控制评估。|博士备用知识，不是当前本科唯一主线。|预印本新、边界仍在变化；具体方法需独立验证。|
