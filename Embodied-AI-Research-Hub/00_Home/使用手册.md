# Embodied-AI-Research-Hub 使用手册

> 这是一份**操作手册**：告诉你每天/每周具体怎么用这个库。  
> 研究定位、资料边界和长期路线看 [`README.md`](README.md)；AI 工作规则看 [`AGENTS.md`](../AGENTS.md)。  
> 核心原则只有一句：**先证据，后叙述；不要把计划写成完成。**

## 1. 30 秒上手

新会话或新的一天，按这个顺序：

1. [`README.md`](README.md)：这个库有什么、边界是什么。
2. [`Current_Status.md`](Current_Status.md)：我现在到底会什么、不会什么。
3. [`Next_Actions.md`](Next_Actions.md)：下一步做什么。
4. [`Dashboard.md`](Dashboard.md)：一页视图。

如果只有 10 分钟：只读 `Current_Status.md` 的“学习状态”和 `Next_Actions.md` 的“最近 7 天”。

## 3. 每天怎么用

### 3.1 开始学习前

只选**一个**最小动作，不要同时开三件事：

- 写一小段代码；
- 读论文的一节；
- 做 3–5 道自测；
- 或修一个具体报错。

把动作写成一句可验收的话，例如：

> “60 分钟内，从空文件写出 `latency_summary.py` 的 `mean` 和 `p50`，并写 3 个测试。”

### 3.2 记录今天

复制 [`Daily_Log.md`](../07_Templates/Daily_Log.md) 到：

```text
05_Reviews/Daily/YYYY-MM-DD.md
```

只写实际发生的事：

- 做了什么；
- 证据在哪（文件/命令/测试/页码）；
- 卡在哪里；
- 明天第一件事。

没有做就写“没有”，不要补造。

### 3.3 结束前

问三个问题：

1. 今天有没有一个**可运行/可检查**的产物？
2. 这个产物能不能证明某个知识点？
3. 有没有需要写进 `Current_Status.md` 的状态变化？

如果第 3 个答案是“有”，但你没有测试/运行记录，就不要改状态。

## 4. 每周怎么用

复制 [`Weekly_Review.md`](../07_Templates/Weekly_Review.md) 到：

```text
05_Reviews/Weekly/YYYY-Www.md
```

周复盘只做四件事：

1. 列出本周实际证据；
2. 写完成/未完成；
3. 提出状态变更（附证据）；
4. 只定下周**一件**最重要的事。

不要写“本周学习 20 小时”，除非你有时间记录。不要用“看了很多视频”代替产物。

## 5. 学一个知识点

### 5.1 建笔记

用 [`Course_Note.md`](../07_Templates/Course_Note.md) 或 [`Concept_Note.md`](../07_Templates/Concept_Note.md)。

每篇至少写：

- 来源/版本/日期；
- 原始内容；
- 我自己的理解；
- 待解决问题；
- 自测；
- 关联课程/项目。

### 5.2 区分四类文字

- **【原始笔记】**：原文/原代码，保留原错。
- **【整理重排】**：只调结构/断行。
- **【AI解释】**：补充说明，不是用户原话。
- **【待核实】/【待纠正】**：不确定或错误；原文保留，更正单列。

### 5.3 “我学会了”怎么办

先说：

> “我学会了 X，先考我。”

然后做 3–5 道题；通过标准是**不看答案能完成**。  
只有通过后，才在 [`Current_Status.md`](Current_Status.md) 把状态改为“已通过独立验收”，并在“状态变更记录”写证据。

有笔记、看过视频、能看懂 AI 的解释，都不够。

## 6. 读论文

1. Zotero 管理条目/PDF/引用；本库不复制 PDF，不改 Zotero 数据库。
2. 先判断：这篇论文与当前哪个研究问题有关？无关就放扩展阅读。
3. 用 [`Paper_Note.md`](../07_Templates/Paper_Note.md)。
4. 没读全文，只写“摘要级/待读”，不写方法细节。
5. 引用写页码/章节/图号；无法核实写“未核实”。

候选清单在 [`Papers_Index.md`](../06_Resources/Papers_Index.md)。不要按团队名气自动加必读。

## 7. 做实验

### 7.1 代码/权重/数据放哪里

- 代码、权重、数据集、Conda/venv、缓存、视频：放**外部实验目录**。
- 本库只放：实验索引、配置摘要、结果表、失败分析、小图/链接。
- 不要把 `*.safetensors`、`*.ckpt`、数据集压缩包放进 `99_Assets/`。

### 7.2 记录一次运行

1. 用 [`Experiment_Record.md`](../07_Templates/Experiment_Record.md)。
2. 在 [`Experiment_Index.md`](../04_Projects/Undergraduate_Thesis/Experiment_Index.md) 加一行。
3. 必填：代码 commit、权重 hash、数据/初态、环境、命令、seed、原始指标、失败分类。
4. 没有原始日志，不写“已复现/已加速/成功率 X%”。

## 8. 改路线

当你说“把学习计划调整一下”：

1. 先写变更提案：改什么、为什么、影响什么；
2. 旧版本复制到 `90_Archive/Old_Roadmaps/`；
3. 更新 [`Current_Roadmap.md`](../01_Roadmap/Current_Roadmap.md) 与 [`Original_V3_Comparison.md`](../01_Roadmap/Original_V3_Comparison.md)；
4. 在 [`Decisions.md`](Decisions.md) 记录理由；
5. 不删除旧版，不覆盖旧文件。

## 9. 用 VS Code / Obsidian / Codex / DSH

### VS Code

```powershell
code D:\Desktop\Embodied-AI-Research-Hub
```

- 用 Markdown Preview 看链接/Mermaid/LaTeX；
- 不要批量重写全库；
- 改完运行检查。

### Obsidian

- 把 `D:\Desktop\Embodied-AI-Research-Hub` 作为**新 Vault** 打开；
- 不要修改现有 `D:\Desktop\Road` Vault；
- 不安装/迁移插件；本库不依赖插件；
- 相对链接、Mermaid、LaTeX 可直接用。

### Codex / DSH

工作目录设为知识库根目录。新会话第一句建议：

> “先读 `AGENTS.md`、`00_Home/README.md`、`00_Home/Current_Status.md`、`00_Home/Next_Actions.md`。今天我们只做一个最小任务：____。不要修改原始资料，不要自动升级学习状态。”

常用指令：

- “记录今天的学习内容”；
- “整理我这周的学习进度”；
- “我学会了 X，先考我”；
- “整理这篇论文，先判断和我的 RQ 有什么关系”；
- “更新本科实验进展，只读真实日志”；
- “我不知道接下来学什么，只推荐一个最小动作”。

## 10. 维护与检查

### 每次改完

```powershell
python tools/verify_hub.py
```

它检查：

- Markdown 相对链接；
- 图片引用；
- 代码围栏/Python 语法；
- 归档 SHA256；
- 473/413 段标记、17 表、32 周行等关键完整性。

### 每周

- 看一次 `verify_report.txt`；
- 确认没有把大文件/密钥放进库；
- 清一次未使用的临时文件；
- 不手动修改 `90_Archive/Original_Documents/` 的原件。

### 每月

- 回看 `Current_Status.md`：有没有“学习中”卡太久；
- 回看 `Decisions.md`：有没有该推翻的假设；
- 回看论文索引：哪些只是收藏、没有读；
- 备份：整个文件夹复制到外部硬盘/学校云（用户明确授权后）。

## 12. 常见问题

| 问题 | 答案 |
|---|---|
| 学习进度写哪里？ | 只写 [`Current_Status.md`](Current_Status.md)；Dashboard 只是视图 |
| Excel 还要更新吗？ | 不；Excel 是 2026-10-13 历史快照 |
| 有笔记就算学会了吗？ | 不算；要独立自测/运行证据 |
| 能改原始 DOCX/Excel 吗？ | 不能；只读，副本在 `90_Archive/` |
| 能改 Zotero/Obsidian 吗？ | 不能擅自改；先备份并获得明确授权 |
| 能复制既有毕设代码吗？ | 不擅自复制/修改/启动；先确认工作区与授权 |
| 权重/数据放哪？ | 外部实验目录；本库不放 |
| 今天没学怎么办？ | 记录“没有”，不补造；第二天从最小动作继续 |
| 旧计划和现实冲突？ | 以证据/Current_Status 为准；改路线先留旧版 |
| 发现概念错误？ | 原文保留，另写【待纠正】，不静默改写 |
| 想加新学习方向？ | 先有真实内容再建笔记；不要预生成空文件 |
| 链接/图片失效？ | 运行 `verify_hub.py`，按报告修 |

## 13. 一句话流程

```text
看 Current_Status
   → 选一个最小动作
   → 做/记录证据
   → 自测或运行
   → 只改有证据的状态
   → 每周复盘
   → 改完跑 verify_hub.py
```
