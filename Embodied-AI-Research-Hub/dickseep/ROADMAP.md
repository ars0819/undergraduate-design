## 1. 一句话目标

用 π₀.₅（openpi）在 LIBERO 上建立**可信基线**，搭一套**可重复的推理性能测量**，据此做**一项有对照实验支撑的加速改进**，形成本科毕设；成果向 OpenFleX 部署与博士阶段的 VLA 高效推理延伸。

### 2.1 官方依赖与硬件要求（openpi README / pyproject，2026-11-01 核对）🟦

| 项 | 要求 | 对你的含义 |
|---|---|---|
| 推理显存 | **> 8 GB** | 12GB 本机**可跑** π₀.₅ 推理 |
| LoRA 微调 | **> 22.5 GB** | 需 4090（24GB），本机不行 |
| 全量微调 | **> 70 GB** | 只有 A100 80GB 可行；40GB 则不能全量 |
| Python | ≥ 3.11（官方用 **uv**） | 3.11.18 满足 |
| 依赖锁 | torch 2.7.1 / jax[cuda12] 0.5.3 / numpy<2 / flax 0.10.2 | **必须独立环境**，不能复用 ml-basic |
| 系统 | 仅在 Ubuntu 22.04 测过 | 版本需确认 |
| 权重 | pi05_base / pi05_libero / pi05_droid | `gs://openpi-assets/checkpoints/…` |
| LIBERO 评测 | `examples/libero`，官方推荐 Docker | 需要 Docker + 无头渲染 |

### 2.2 算力环境（2026-11-03 核实）🟦

| 机器 | 配置 | 驱动 / CUDA 上限 | 定位 |
|---|---|---|---|
| `734-a100`（10.112.164.80） | RTX 3090 **24GB**，Ubuntu 22.04.5 | 580.159.03 / CUDA 13.0 | **主力**：openpi 推理 + LoRA（正是官方示例的 24GB 档） |
| `wq` | 2 × A100 **40GB**（不合并） | 535.309.01 / **CUDA 12.2** | 暂缓；驱动升级后再做全量与批量评测 |
| 本机 | RTX 5070 12GB | CUDA 12.8 | 开发 + 单次推理 profiling |

- A100 单卡 40GB **做不了全量微调**（需 > 70GB）；双卡 FSDP 是后续选项，不是毕设必需 🟦
- `wq` 的 535 驱动可能带不动 openpi 的 torch 2.7.1 / jax 0.5.3 轮子 🟥 待实测；不行就申请升级到 550+

## 3. 选题定位

**不追"新算法"，追"可信测量 + 一项被证实的改进"。**

- 贡献 1（必做）：π₀.₅ 在 LIBERO 上的可复现基线 + 固定评测协议
- 贡献 2（必做）：分模块推理性能测量（视觉编码 / VLM 主干 / action expert / 动作块）
- 贡献 3（核心）：一项加速改进 + 对照实验 + 消融
- 贡献 4（选做）：评测协议敏感性（种子、episode 数、推理频率对成功率的影响）
- **不做**：真机作为主要证据；世界模型；双系统整机；扩散模型理论

## 4. 候选路线与结论

| 路线 | 结论 | 理由 |
|---|---|---|
| π₀.₅ / openpi + LIBERO | ✅ 主线 | 与组内同构；官方权重 + 官方评测配置；推理 8GB、LoRA 22.5GB 门槛明确 |
| SmolVLA + LIBERO | 🟡 备选 / 练兵 | 450M 好跑；但官方 ckpt 复现存在公开争议，成功率基线不稳 |
| OpenVLA 7B 本地复现 | ❌ 不选 | 14GB 权重放不进 12GB；量化会让基线多一个变量 |
| 扩散动作生成加速 | ❌ 不作主题 | 数学清楚但离组内主线远，已有大量工作 |
| 双系统局部推理优化 | ❌ 现在太早 | 系统尚不存在，缺可测量对象 |
| pokebot / RoboAPI | ❌ 不作基线 | 云端黑盒，测不到内部耗时；单臂，接不了 OpenFleX 🟦 |

## 5. 复现做到哪一层

| 层 | 内容 | 做不做 | 验收 |
|---|---|---|---|
| L1 | 加载权重、单次推理 | ✅ | 跑出合法动作（本机 12GB） |
| L2 | LIBERO 重现论文数字 | ✅ 核心 | 与论文差 ≤ 5 个百分点 |
| L3 | 公开数据微调 | 🟡 选做 | 单 suite 小规模，loss 正常下降；需 4090/A100 |
| L4 | 论文完整训练复现 | ❌ | 需 ≥70GB，投入产出比过低 |

## 6. 最小可信基线（先按这个跑，不要一上来全套）

| 项 | 取值 |
|---|---|
| Benchmark | LIBERO-Spatial + LIBERO-10 |
| 迭代用 | 10 任务 × 10 次 = 100 / 套 |
| 最终报告 | 10 任务 × 50 次 = 500 / 套 |
| 必报指标 | 成功率、延迟 P50/P95、峰值显存、分模块耗时、动作块长度 |
