# 北京邮电大学 2027 届本科毕业设计（论文）研读笔记
### —— 面向机械工程专业学生

> 依据：①《北京邮电大学本科毕业设计（论文）管理办法》（校发〔2023〕14 号，2023-07-10 印发，自 2024 届起执行）；②《2027 届本科毕业设计（论文）工作安排》；③《2027 届本科毕业设计（论文）指导手册》（2026 年 9 月修订）。
> 说明：①②为全校性制度，③是本届的执行细则，冲突时以③（更新、更细）为准，再以学院实施细则为最终落地口径。文中"手册第 X 条"可直接回原文核对。

---

## 0. 一句话结论

这不是"最后写篇论文"的事，而是一条**卡点密集的流水线**：选题 → 任务书 → 开题 → 中期答辩 → 内审 → 查重 → 格式检测 → 答辩。**四个"不合格即不能答辩"的硬闸门**（内审、查重 ≤25%、格式检测、答辩申请表签字）都排在春季学期第 9—15 周，而这段时间恰好也是画图、跑仿真、补实验最忙的时候。真正的胜负手是**秋季学期把题目和方案定死**，春季只做执行。

## 1. 全流程节点表（2027 届）

周次为校历周次，月份为估算值，**以教务处/学院通知和校历为准**。

| 阶段 | 时间 | 你要做的事 | 交付物 / 卡点 |
|---|---|---|---|
| 启动 | 秋 第 9 周（约 10 月下旬） | 关注学院通知、参加培训 | — |
| 教师出题 | 秋 第 10—11 周（约 11 月上中旬） | **现在就在这一步**：看题目库、找导师沟通意向 | 题目经学院审定后公布 |
| 选题 + 任务书 | 秋 第 12—14 周（约 11 月中下旬） | 系统内选题、师生互选；接任务书、定进度、开始查资料 | 《任务书》（含题目类型、来源、主要内容、技术要求、参考文献、进度） |
| 开题 | 秋 第 15—18 周（约 12 月） | 写《开题报告》，签字版上传系统；接受学院开题检查、教务处抽查 | **≥1500 字，参考文献 ≥10 篇且以近五年为主** |
| 研究（一） | 秋 第 19—20 周 + 春 第 1—2 周（约 1 月—2 月底） | 方案设计、建模/仿真、试制与实验 | 指导教师**每两周至少沟通 1 次**并记录 |
| 中期检查 | 春 第 3—4 周（约 3 月上中旬） | 填《中期进展情况检查表》，线下中期答辩 | **≥1000 字；提交不少于 1/2 的论文整体框架；答辩 15 分钟（陈述 ≥5 分钟）** |
| 研究（二） | 春 第 5—8 周（约 3 月中—4 月中） | 完成全部工作 + 撰写论文 | 论文正文 **理工科 ≥15000 汉字** |
| 院级内审 + 查重 | 春 第 9—11 周（约 4 月中—5 月初） | 先内审→按意见改→再查重（≤25%）→格式检测 | **内审 100% 覆盖；查重 2 次机会，末次不过不得答辩** |
| 校级抽审 + 答辩 + 评优 | 春 第 12—15 周（约 5 月） | 抽审（约 5%）；线下盲答辩 20 分钟；答辩后 3 天内改完并上传定稿 | 成绩一周内录入；院级优秀 ≤25%，校级优秀 ≤2% |

**关键顺序（容易踩坑）**：内审 → 按内审意见修改 → 查重 → 格式检测 → 填《答辩申请表》（导师签字）→ 答辩组审核 → 才能答辩。查重必须在**答辩前两周内**完成，格式检测**不限次数但必须合格**。

## 2. 五条红线（触碰即失去答辩资格或按不及格处理）

| # | 红线 | 依据 |
|---|---|---|
| 1 | **查重总文字复制比 >25%** 且末次仍未通过 → 不得答辩（2 次机会） | 手册第十四条 |
| 2 | **格式检测不合格** → 不得答辩（次数不限，别拖到最后） | 手册第十五条 |
| 3 | **未经批准不参加线下中期答辩/线下答辩** → 当次成绩无效 | 手册第十三条、第二十六条 |
| 4 | **AI 工具直接用于开题报告、中期报告、论文撰写** → 按"**代写**"认定；导致数据图表失实 → 按"**伪造数据**"认定 | 手册第十八条 |
| 5 | 抄袭、伪造、篡改、代写、买卖论文 → 按不及格处理 | 手册第八条（五）、第四十条（五） |

> AI 工具允许的用途只有三类：**文献调研、数据处理、引文整理**。核心论点和创新贡献必须本人完成；**用了就要在论文里单独一段明确说明**。这条同样约束我：我可以帮你检索文献、清洗实验数据、写仿真脚本、查格式和图表规范，但不能代写开题报告、中期报告和论文正文。

## 3. 分数怎么来的：30 / 20 / 50

总评 = **中期检查 30% + 指导教师 20% + 答辩 50%**（学院可微调）。80 分以上才是"良好"，90 分以上"优秀"。

### 3.1 指导教师 20 分（细则见《成绩评定表》）

| 维度 | 分值 | 机械生的抓手 |
|---|---|---|
| 调研论证 | 3 | 文献要独立查、要有加工分析，不能只罗列 |
| 方案设计 | 3 | 有可行性论证、有对比选型（不是拍脑袋定结构） |
| 能力水平 | 3 | 会用所学知识解决**复杂工程问题**、正确处理实验数据 |
| 学习态度 | 3 | 每两周沟通记录、按期交付 |
| 设计（论文）水平 | 5 | 文题相符、立论正确、结论严谨、有应用价值 |
| 文本规范 | 3 | 装订顺序、字号字体、符号统一、图表编号齐全 |

### 3.2 答辩 50 分（这是最大的一块，也是最能拉开的）

| 维度 | 分值 | 说明 |
|---|---|---|
| 选题 | 5 | 符合专业培养目标、结合工程实际、难易适度、有新颖性和综合性 |
| 设计（论文）质量 | 20 | 全面完成**任务书**要求、工作量饱满、写作规范、有理论或应用价值 |
| 答辩准备 | 5 | 准备充分、PPT 简洁清晰、准时 |
| 内容陈述 | 15 | 逻辑清楚、重点突出、掌握透彻 |
| 回答问题 | 5 | 准确、有深度、有理论依据、概念清晰 |

**结论**：答辩 50 分里，20 分是"论文质量"、15 分是"讲得清"。所以①任务书里写的东西必须全部做到（评的是"完成任务书规定的各项要求"）；②陈述 10 分钟要练到能在 9 分钟讲完还留得住重点。

## 4. 论文规范速查（照抄执行）

### 4.1 版面
- A4 纵向，无文档网格；**四边页边距 2.5 cm**，页眉页脚 1.5 cm。
- 页眉：**"北京邮电大学本科毕业设计（论文）"**，小五宋体，居中；只加在 正文→参考文献→致谢→附录。
- 页码：居中、宋体小五；**目录用罗马数字（Ⅰ、Ⅱ…）**；**正文起用阿拉伯数字（1、2…）**；封面、诚信声明、授权说明、中英文摘要**不编页码**。
- 题目 ≤ **36 个汉字**（含副题和标点）。

### 4.2 字体字号（最常被格式检测抓的地方）

| 部分 | 规格 |
|---|---|
| 中文摘要标题"摘要" | 黑体三号，居中，段后 1 行，单倍行距 |
| 摘要正文 | 宋体四号，两端对齐，首行缩进 2 字符，**固定值 20 磅** |
| "关键词：" | 黑体四号；关键词宋体四号，**3—5 个，分号隔开**，段前 1 行 |
| ABSTRACT 标题 | Times New Roman 三号加粗，居中，段后 2 行 |
| 英文摘要正文 | TNR 四号，首行缩进 2 字符，固定值 20 磅 |
| "目录" | 黑体三号居中；一级目录 黑体小四；二/三级 宋体小四（左缩进 2/4 字符） |
| 章标题 | **黑体三号，居中**，段后 2 行，**每章另起一页** |
| 二级标题 | 黑体四号，段前段后各 0.5 行 |
| 三级标题 | 黑体小四，左对齐 |
| 四级标题 | 宋体小四，缩进 2 字符 |
| 正文 | **宋体小四**，两端对齐，首行缩进 2 字符，**固定值 20 磅** |
| 引文/语料/案例 | 可楷体五号 |
| 图题、表题 | **楷体五号，居中**；图题在图**下方**、表题在表**上方**，题名后不加标点 |
| 参考文献标题 | 黑体三号加粗居中；条目 中文宋体五号 / 英文 TNR 五号，固定值 20 磅 |
| 致谢、附录标题 | 黑体三号加粗居中 |

### 4.3 结构
- **章节编排（工科）**：第一章 / 1.1 / 1.1.1 逐级递进。**不要**用"第一节、一、（一）"那套（那是人文经管的写法）。
- **正文 ≥15000 汉字**（理工科）。注意这是正文字数，不含摘要、目录、参考文献。
- 定稿装订顺序：**封面 → 诚信声明+使用授权说明（一页）→ 中文摘要（含关键词）→ 外文摘要（含关键词）→ 目录 → 正文 → 参考文献 → 致谢 → 附录**。
- 过程性文件装订顺序：**任务书 → 开题报告 → 中期检查表 → 查重报告 → 格式检测报告 → 答辩申请表 → 成绩评定表（签字盖章版）→ 团队/校外/提前申请表（如有）→ 教师指导记录表 → 其他**。

### 4.4 图表、公式、参考文献
- 图：编号"图 1-1"，有图题，具**自明性**（不看正文也能懂）；分图用（a）（b）（c）并各有分图名；全文编号方式统一；有英文标题则用 Figure 1-1。
- 表：**三线表**，编号"表 1-1"，表题**中英文都要**；跨页续表要重复表头并标"续表 2-1"；有英文标题则用 Table 1-1。
- 公式：两个以上就要编号，编号放括号内、**右端对齐**（1-1）；长公式只能在 + − × ÷ ≤ ≥ 等符号处转行。
- 参考文献：**≥10 篇**，按正文引用顺序排列，引用处右上角方括号标号；作者 <3 人全列，>3 人列前 3 位加"等"；中外人名**姓在前、名在后**；其余按 **GB/T 7714-2015**。
- **题目来源于科研项目的，必须在正文第一页加脚注写明项目名称和编号**（宋体/TNR 五号，固定值 12 磅）。这一条最容易被忘，而它恰好是"选题结合科研"的加分证据。
- 计量单位按国家法定计量单位（SI）书写。

## 5. 机械工程专业专属提醒（文件里没细说，但会扣分的地方）

1. **题目类型选"工程实践类"或"研究设计类"**。手册把选题分四类：工程实践类（技术原理→技术实现，还要回答是否环保、有无市场）、研究设计类（关键技术有创新）、理论分析类、其他。机械本科毕设绝大多数属前两类，任务书里那一栏别乱勾。
2. **"图纸完备、整洁、正确"是明文评分项**（优秀档要求），且不及格档明确写"图、表、设计中的图纸……不能正确执行国家相关标准"。所以图纸要按国标来：幅面与格式 GB/T 14689、标题栏 GB/T 10609.1、明细栏 GB/T 10609.2、机械制图 GB/T 4457/4458、尺寸公差 GB/T 1800、几何公差 GB/T 1182、表面结构 GB/T 131。**装配图 + 零件图 + 明细表（BOM）三件套**建议齐备。
3. **盲答辩（100%）**：图纸标题栏、封面、致谢里不要出现导师和本人信息，具体按学院盲审版要求处理（**先问学院教务**，各院做法略有差异）。
4. **工程教育认证要求**：手册第七条明确任务书要"理清与指标点的对应关系"，第十二条、第三十七条也把"毕业要求""认证要求"写进了成绩评定口径。若你专业按认证要求执行（这属学院口径，报到时问一句教务即可），任务书里的"主要内容/技术要求"最好能对上毕业要求指标点（设计/开发解决方案、研究、使用现代工具、工程与社会等）——中期和答辩时专家常问"你这个工作对应哪条毕业要求"。
5. **团队毕设（3—5 人）**：机械类整机课题常拆成机构设计 / 传动与控制 / 仿真与优化等子题。规则是**每人一个独立子题目、每人一篇独立论文、分工明确且有实质协作**，还需填《团队毕设申请表》，且由指导教师负责人所在学院统一组织。
6. **"原始数据搜集得当，实验或计算结论准确可靠"是评分项**。仿真类务必留存：网格与无关性验证、边界条件、收敛判据、材料参数来源；实验类留存原始记录本与标定数据。答辩 5 分的"回答问题"基本就靠这些细节撑住。
7. **数据图表要经得起追问**：手册把"未审慎使用 AI 导致数据图表失实"直接定为伪造数据。用工具做数据处理可以，但每个图的原始数据要能回溯。
8. **每两周一次沟通要留痕**：《教师指导记录表》由教师填写、每两周一行，双面打印。主动汇报 = 你的"学习态度 3 分"+ 过程管理的证据。

## 6. 现在（2026 年 11 月初）应该做的 6 件事

1. **确认自己处在哪个周次**（教务处通知/校历），因为教师出题（第 10—11 周）到选题（第 12—14 周）只有两三周窗口。
2. **锁定导师和方向**：一人一题、双向互选；每位导师原则上带 ≤6 人。优先找有在研项目、能提供样机/实验条件/软件（SolidWorks、ANSYS、ADAMS、MATLAB 等）的老师——题目来源勾"来源于科研项目"是加分项（记得写脚注）。
3. **看题目是否踩雷**：与往届题目相似度高会被要求重新拟定；题目 ≤36 汉字；必须落在机械工程培养目标内。
4. **提前攒文献**：开题报告要 ≥10 篇、以近五年为主，现在就开始用知网/Web of Science/Engineering Village 建库，做好引文管理（这一步是 AI 工具**允许**的用途）。
5. **把"成果形态"想清楚**：整机？机构？测试台？仿真优化？——它决定你要不要画图纸、做样机、跑实验，也决定春季第 5—8 周够不够用。
6. **建三个文件夹**：`01_过程材料`（任务书/开题/中期/申请表）、`02_原始数据`（实验记录、仿真设置、图纸版本）、`03_论文`。毕设最常见的翻车不是能力不够，而是材料找不到、版本对不上、签字漏一张。

## 7. 其他可用政策（可能对你有用）

- **提前毕设**：学有余力、参加过科研训练/大创的，可申请提前进入毕设环节（学院审核、教务处审批）。
- **高水平创新成果替代毕设**：全日制大三/大四、且是成果主要完成人；成果须含问题分析、调研、方案设计、论证、实施全过程并符合专业核心培养目标；**已用于认定课程学分的成果不能重复使用**；团队成员须签字同意由你单独以该成果申请。
- **校外/国外做毕设**：须填《校外完成毕设审批表》，配一名校内导师，**校内外双导师签字**；答辩一律回本学院。
- **成绩复议**：成绩公布后 **3 日内**提交书面申请，学院在毕业资格审查前组织复议，复议结果为最终成绩。
- **存档**：材料电子存档至少 4 年，优秀论文 6 年以上——所以定稿上传后再改就来不及了，答辩结束后 3 天内是最后窗口。
