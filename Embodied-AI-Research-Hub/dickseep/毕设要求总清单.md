## 三、选题环节的全部规则（当前最急）

| 规则 | 内容 |
|---|---|
| 一人一题 | 团队毕设也须每人有独立子题目、独立论文 |
| 数量上限 | **每位教师申报题目 ≤3 项**；**每位教师指导学生 ≤6 名** |
| 机制 | 指导教师与学生**双向互选**，学生提意向、教师同意后确定 |
| 专业符合性 | **题目和实际论文内容必须符合学生当前本科专业的培养方向**；对保研至外院/外校的学生同样适用 |
| 变更 | 一经确定**原则上不得更换题目和指导教师**；确需变更须学生在系统提出申请、导师和学院批准 |
| 申报主体 | 原则上所有题目由**第一指导教师**申请 |

### 3.1 三种"非本院导师"情形的处理

| 情形 | 谁申报 | 额外材料 | 关键要求 |
|---|---|---|---|
| 本院教师 | 本院教师 | — | — |
| **外院导师**（如信通院） | **由外院老师申请**；学生自行在共享表格填题目、导师、学生信息，标注"**院外**" | 待确认（见第九节） | 论文须回本学院中期答辩和答辩 |
| **校外导师**（企业/外单位） | 由**院内第二指导教师**负责系统申报 | **附件6 + 附件7**，**11 月 13 日前交焦老师** | 必须配一名院内教师；所有签字表格须校内外双导师签字 |

### 3.2 指导教师资格
- 中级及以上职称、有经验的教学/研究/工程技术人员
- 校内导师须持"高等学校教师资格证"+"北京邮电大学授课准入证"
- 校外导师由学生所在学院审核资格；须与校内教师合作指导

## 五、五个"不过就不能答辩"的硬闸门

| # | 闸门 | 标准 | 后果 |
|---|---|---|---|
| 1 | **院级内审** | 100% 全覆盖，每篇至少 1 位非指导教师评议 | 不通过不能进入查重 |
| 2 | **查重检测** | 总文字复制比 **≤25%**（学院可另定）；**至多 2 次机会**；末次未过 | 不得参加答辩 |
| 3 | **格式检测** | 次数不限，但结论必须"合格" | 不合格不得答辩 |
| 4 | **线下答辩出席** | 未经批准不参加线下中期答辩/答辩 | 当次成绩无效 |
| 5 | **学术诚信** | 抄袭、伪造、篡改、代写、买卖 | 按不及格处理 |

**AI 工具红线**（实施细则第四条、指导手册第十八条）：
- 允许：**文献调研、数据处理、引文整理**
- 严禁：直接用于**开题报告、中期报告、论文撰写**（含视频制作）→ 按"**代写**"认定
- 未审慎使用导致数据图表失实 → 按"**伪造数据**"认定
- 如使用，须**单独段落明确说明**

## 六、论文规范（格式检测就看这些）

### 6.1 版面
- A4 纵向，无文档网格；**四边页边距 2.5 cm**；页眉页脚 1.5 cm
- 页眉："北京邮电大学本科毕业设计（论文）"，**小五宋体**，居中（正文→参考文献→致谢→附录）
- 页码：居中、宋体小五；**目录用罗马数字（Ⅰ、Ⅱ…）**；**正文起用阿拉伯数字**；封面、诚信声明、授权说明、中英文摘要**不编页码**
- **题目 ≤36 个汉字**（含副题和标点）

### 6.2 字号
| 部分 | 规格 |
|---|---|
| "摘要" | 黑体三号，居中，段后 1 行 |
| 摘要正文 | 宋体四号，首行缩进 2 字符，**固定值 20 磅** |
| "关键词：" | 黑体四号；关键词宋体四号，**3—5 个，分号隔开** |
| ABSTRACT | Times New Roman 三号加粗，居中，段后 2 行 |
| 英文摘要正文 | TNR 四号，固定值 20 磅 |
| "目录" | 黑体三号居中；一级 黑体小四；二/三级 宋体小四（缩进 2/4 字符） |
| 章标题 | **黑体三号，居中，每章另起一页** |
| 二级 / 三级 / 四级标题 | 黑体四号 / 黑体小四 / 宋体小四（缩进 2 字符） |
| 正文 | **宋体小四**，两端对齐，首行缩进 2 字符，**固定值 20 磅** |
| 图题、表题 | **楷体五号，居中**；图题在图下、表题在表上，题名后不加标点 |
| 参考文献/致谢/附录标题 | 黑体三号加粗居中 |

### 6.3 结构与编号
- 工科用 **第一章 / 1.1 / 1.1.1** 逐级递进（不要用"第一节、一、（一）"）
- 图编号"图 1-1"、表编号"表 1-1"，**表用三线表**，**表题中英文都要**；跨页续表重复表头并标"续表 2-1"
- 公式 ≥2 个须编号，放括号内、**右端对齐**（1-1）
- 参考文献 **≥10 篇**，按正文引用顺序，作者 >3 人列前 3 位加"等"，其余按 **GB/T 7714-2015**
- **题目来源于科研项目的，正文第一页加脚注写项目名称和编号**（宋体/TNR 五号，固定值 12 磅）

### 6.4 装订顺序
- **定稿**：封面 → 诚信声明+使用授权说明（一页）→ 中文摘要（含关键词）→ 外文摘要（含关键词）→ 目录 → 正文 → 参考文献 → 致谢 → 附录
- **过程性文件**：任务书 → 开题报告 → 中期检查表 → 查重报告 → 格式检测报告 → 答辩申请表 → 成绩评定表（签字盖章版）→ 团队/校外/提前申请表（如有）→ 教师指导记录表 → 其他

## 七、成绩与评优

| 项 | 规则 |
|---|---|
| 成绩构成 | **中期检查 30% + 指导教师 20% + 答辩 50%**（学院可微调） |
| 五级换算 | 100—90 优秀；89—80 良好；79—70 中等；69—60 及格；<60 不及格 |
| 答辩时长 | **20 分钟**：陈述 10 分钟 + 提问 10 分钟 |
| 答辩小组 | 3—5 人（专家 ≥3 人 + 秘书 1 人）；**100% 盲答辩 + 导师回避** |
| 复议 | 成绩公布后 **3 日内**书面申请，复议成绩为最终成绩 |
| 院级优秀率 | **≤ 25%** |
| 校级优秀 | 成绩须"优秀"且**首次查重 ≤10%**；推荐数 **≤ 2%** |
| 校级抽审 | 比例约 **5%**，在内审完成后进行 |

**指导教师 20 分细项**：调研论证 3 + 方案设计 3 + 能力水平 3 + 学习态度 3 + 设计（论文）水平 5 + 文本规范 3
**答辩 50 分细项**：选题 5 + 设计（论文）质量水平 20 + 答辩准备 5 + 内容陈述 15 + 回答问题 5

## 九、四件待确认的事（文件之间没对齐）

1. **保研外院（信通院）要不要填附件6/附件7？**
   通知把"外院"和"校外"分开写，但附件7 的表名是"校（**院**）外毕业设计申请表"。**建议直接问焦老师**：保研外院是只标"院外"，还是要交附件7。

2. **外院导师的题目怎么进教务系统？**
   通知说"保研外院的题目由外院老师申请"，但又说"学院统一组织题目审核，审核通过后方可由第一指导教师……在教务系统发起申报"。**外院老师有没有本院系统权限？**需要问清谁点"提交"。

3. **学院工作安排与启动通知的日期有出入**（审核窗口 11/16—12/4 vs 11/14—11/27 + 11/28—12/6）。以通知为准，但**任务书下达时间可能提前**，别等。

4. **"院外"学生回本学院中期答辩和答辩**——细则只写了校外，没写外院。按指导手册"跨学院做毕设的学生应回其所属学院参加中期答辩和答辩"执行。
