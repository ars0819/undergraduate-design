# embodied

这个仓库收录 SmolVLA 的中文源码学习材料、论文精读和 LIBERO 复现记录。所有资料集中在 `smolvla/`。 [打开 SmolVLA 资料目录](smolvla/README.md)

## 从哪里开始

- **第一次读源码**　从「零基础快速开始」入手。指南包含五阶段学习路线，以及工作区、LeRobot 目录和 Python 包的用途。 [源码学习指南](smolvla/smolvla-reading/GUIDE.md)
- **动手做第 1 课**　用纯 Python 练习模块导入和函数调用。目录里有可运行的示例、两道填空练习和单独的参考答案，练习页附 Windows PowerShell 命令。 [第 1 课练习](smolvla/smolvla-reading/tutorials/01_imports/README.md)
- **打开带注释的源码**　按原有文件路径查找 SmolVLA 配置、模型加载、动作队列和 LIBERO 评测。 [中文注释源码](smolvla/lerobot/)
- **对照论文与实验**　查阅中文精读笔记、教学图，以及 LIBERO 复现的视频、日志和指标。 [论文精读与复现](smolvla/smolvla-精读复现/README.md)

论文原文可在 arXiv 阅读。 [SmolVLA 论文](https://arxiv.org/abs/2506.01844)
